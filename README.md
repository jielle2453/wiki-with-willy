# wiki-with-willy

**把你多年累積的資料夾，變成一個會回答問題的知識庫。**

wiki-with-willy 是 Claude 桌面版的外掛。你的檔案照常放在原本的資料夾，它會把每一份讀過、整理好，彙整成每個案子、每位客戶、每家廠商的一頁現況。之後想知道什麼，用說的問就好；交代的事、約好的日期，也用說的記下來。

作者：呂冠佑、呂筱婕

## 為什麼選 wiki-with-willy

### 每個回答都有出處
回答不是憑印象。每一句都標明來自哪份檔的第幾頁，或你哪天說過的話，點一下就開原檔。數字會回原檔逐份核對、由程式加總；兩份檔寫法不一樣時，兩邊都會告訴你，不會替你挑一個。

### 你的原檔，一個字都不會被改
AI 只讀你的原檔，不會直接修改或刪除。要改的文件一律先做副本，成品另外存放；要搬、改名、刪除時先講清楚，你同意才做，刪的檔進資源回收筒。

### 做錯了，一句話就退回
AI 每次動手前都會先備份。不滿意，說「退回上一版」就回到原樣，連資料夾的改名、搬動都能還原。

### 你說不讀，就真的讀不到
不想讓 AI 看的資料夾，和檔名看起來像密碼、金鑰的檔，有獨立的守門程式擋著，不是只靠 AI 自律。密碼只存在這台電腦的 Windows 憑證管理員，不會出現在知識庫的任何檔案裡。

### 用說的就好，不用學軟體
不用學分類、標籤或資料庫。交代事情、更正錯誤、改整理的方式，都直接在對話裡說。AI 要你決定的事會集中在一處，每次只問跟當下有關的幾件。

### 越用越懂你
你說過的話、做過的決定、糾正過的錯，都會記下來寫進現況，下次不用再說一次。回答的長短、日期的寫法、文件的格式，照你的習慣來。

### 檔案再多也不卡
大量檔案會在背景分批整理，整理的同時照常可以問。新檔進來、舊檔改版，開對話時會自動發現並更新。

### 資料在你自己的電腦
知識庫就是你電腦上的一個資料夾，用 Obsidian 也打得開，備份、搬家、換電腦都有完整的流程。

## 主要功能

- **問答**：查現況、找檔案、算數字、比較差異、回顧最近做過的事，回答都附出處。
- **整理**：Word、Excel、PowerPoint、PDF（含掃描檔）、圖片，每份整理成一張卡；同一件事的卡再彙整成一頁現況。
- **日程**：會議、期限、承諾、案子的進度與結案都記得住，整理檔案時讀到的日期也會自動加進來；開對話時提醒逾期和這週要做的事。
- **做文件**：報價表、進度報告、簡報、合約修訂，先給草稿、核對數字，你確認後才做成檔。
- **收件匣**：拖進對話的檔、貼上的截圖都能直接收進知識庫，整理完再幫你決定放哪個資料夾。
- **健檢**：每週在背景檢查一次，能修的自己修，每月一份報告。
- **備份與搬家**：一句話備份整個知識庫，還原前先演練並告訴你哪些會不見，換電腦、換位置都有完整流程。
- **自動升級**：小修正在背景自動套用，大更新先問你；換版前先在你的電腦試跑新版，跑不起來就不換。

## 環境需求

- Windows 10 或 11
- Claude 桌面版（更新到最新）
- Python 3.10 以上
- 選配：讀 PDF 需要的元件會在建置時詢問安裝；轉 PDF、重算 Excel 需要 Office 或 LibreOffice

## 安裝與建置

第一次由服務人員到場安裝並建好知識庫：

1. 裝好 Python，並把 Claude 桌面版更新到最新。
2. 在 Claude 桌面版的外掛畫面新增市集，貼上這個網址，再安裝 wiki-with-willy，然後重開 Claude：

   ```
   https://raw.githubusercontent.com/jielle2453/wiki-with-willy/main/marketplace.json
   ```

3. 開一個空資料夾的對話，打 `/wiki-with-willy:build`。AI 會一步一步帶著做：檢查電腦、訪談、試整理、全部整理、確認名字，最後交一份建置報告。一天做不完，隔天再打一次會接著做。

之後只要在這個資料夾開對話就能用。

## 注意事項

- 守門程式靠 Python 執行。Python 壞掉時，Claude 會被一併擋下來；先修好 Python，或在外掛畫面暫時停用 wiki-with-willy。
- 停用或移除外掛不會刪掉知識庫，裝回來就接上；但停用期間沒有程式守著不讀的資料夾。
- AI 讀過的內容會送到 Claude 處理，這一點跟一般使用 Claude 相同。帳號密碼請不要直接打在對話裡。

## 這個 repo 放什麼

只放發行版：`marketplace.json`（目前的版本與下載位置）、`rollout.json`（各版本的推送對象），每一版的 zip 在 [Releases](https://github.com/jielle2453/wiki-with-willy/releases)，改了什麼見 zip 裡的 `CHANGELOG.md`。
