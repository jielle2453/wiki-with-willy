# wiki-with-willy

日期：2026-10-16
給誰看：服務人員與使用者。
什麼時候更新：發行時，隨 CHANGELOG 一起。

## 這是什麼

把客戶既有的資料夾建成 AI 維護的知識庫的 Claude Code plugin：問、答與出處、剛做了什麼、退回、要我決定什麼、資料去了哪。

## 怎麼載入

開發期用 `--plugin-dir` 直接指到這個 repo 的資料夾：

```
claude --plugin-dir "<repo 路徑>"
```

這是開發期的載法，不會安裝到 Claude Code 的 plugin 快取；正式的安裝與升級方式之後補。

## 怎麼用

加資料夾、不讀某夾：在知識庫的對話裡直接說，AI 會先講清楚再做。例如：

- 「把 D 槽的報價也加進來」：AI 請你貼完整路徑，先報有幾份檔、哪些檔名像密碼不會讀，你說好才加。
- 「不要讀公司行政裡的薪資」：AI 問你是不想讓 AI 看到，還是只是用不到，你選了才排除。
- 「客戶案件那個資料夾不要了」：AI 問你是以後不讀還是要刪檔；拿掉只是不讀，檔案不動，說「退回上一版」救得回。
- 「你現在讀哪些資料夾」：AI 列出登記的資料夾和不讀的夾。

加進來的資料夾會入清冊（`.system/inventory.json`），記每份檔在哪、多大、內容指紋。每次開對話，開場會先快速比一次，有變動就多一行「變動：新增 N、修改 N、不見 N」；搬動、改名、多一份一樣的不算變動。某個資料夾這台電腦找不到（外接硬碟沒插、搬走了），開場報一次，其他照常。Word、Excel、PowerPoint 另存但內容沒變，不算修改。

### 整理成卡

每份檔會整理成一張檔案卡，放在 `檔案索引/`（夾的結構照原檔），卡上寫這是什麼、重點、日期與數字、提到的人與單位，每點標原檔的頁數或列數，還有一條連結點了開原檔。總資料夾最上層的 `總目錄.md` 列出全部的卡，可以摺疊（Obsidian 也看得懂）。

- 加完資料夾 AI 會問「要我現在整理成卡嗎？」；之後開對話時開場看到有變動，AI 先回答你問的，再自己整理，回答最後說整理了哪些。一次超過 5 份會先問你。
- Word、Excel、PowerPoint、純文字（含 Big5 舊檔）由程式抽字；PDF 與圖片由 AI 直接讀原檔（PDF 一次最多讀 20 頁，更長的先讀前面、卡上標「部分」；圖片型 PDF 照看到的寫）。不用另外裝東西。
- 讀不到的檔（有密碼、`.doc` 這種舊格式、只在雲端還沒下載）不做卡，記在 `系統/待處理.md`，寫了怎麼處理。檔名像密碼或金鑰的檔不讀、不做卡。
- 你刪掉的檔，AI 會問「是你刪的嗎？」，你明確說是才把卡拿掉，說「退回上一版」救得回；不是刪的，從資源回收筒或雲端找回來就好。檔案搬到別夾，卡會跟著搬。
- 卡上只記身分證、帳號這類個資的「種類」，不抄號碼；統編、電話預設也只記種類。

服務人員在終端機可以直接跑（前綴是開場那行印的 kb 指令）：

- `kb changes`：跟清冊上次掃描比，列新增、修改、搬動、不見的檔名；只看不改。`--all` 列全部，`--quick` 走開場那條快的路。
- `kb inventory scan`：全掃一次，把變動套進清冊；寫前先備份，說「退回上一版」救得回。`--source <別名>` 只掃一個來源。原檔不見的會記進待處理，找回來自動關掉。
- `kb cards todo`：列還沒有卡、該重做、該搬的卡與讀不到、原檔不見的份數；只看不改。`--json` 全列。
- `kb cards sync`：原檔搬了，卡跟著搬；`kb cards drop <編號>`：原檔已刪，拿掉它的卡；`kb cards index`：重寫 `總目錄.md`。
- `kb convert <編號或路徑>`：把一份檔抽成純文字暫存檔（`.system/temp/`，24 小時後清掉），終端機不印內容；PDF、圖片只印路徑。
- `kb pending list|resolve|dismiss`：看、處理 `系統/待處理.md` 的事。

搬檔、改名、資料夾搬家、重建知識庫這版還做不到，AI 會說怎麼自己做。

## 狀態

建置中。0.8.0 有守門、事務層、骨架與來源登記、工作日誌、開場注入與核心規則、第一個 skill manage、清冊：`kb init` 建總資料夾，`kb folders add|exclude|list` 登記客戶的資料夾與不讀的夾；知識庫裡開對話時，客戶原檔只讀、排除的夾不讀、檔名像密碼或金鑰的檔不讀（客戶說可以才讀）、`kb.py` 不用按允許；每句話一個回合，AI 改綜合卡、檔案索引、AI 產出前先備份，說「退回上一版」就退，AI 產出會登記；一句話改超過 10 張綜合卡會先停下來問；對話裡打的帳密不會原樣記進系統檔。每句話問了什麼、AI 答了什麼、做了什麼、改了哪些檔記進 `系統/工作日誌/`（建知識庫、加資料夾、退回這些程式自己做的事也有一段），問「最近改了什麼」由腳本 `kb journal recent` 讀。每個對話一開始 AI 就拿到十四條核心規則與 `kb.py` 的位置，摺疊後也會重新拿到；python 沒跑起來時 AI 會說程式沒啟動並停手。在對話裡說「把 D 槽的報價也加進來」「不要讀私人那夾」「那個資料夾不要了」「私人那夾還是讀好了」「現在讀哪些資料夾」就會做（manage）；搬檔、改名、搬家、重建還做不到。加進來的資料夾會入冊，每次開對話先快速比對、開場印「變動：新增 N、修改 N、不見 N」，找不到的資料夾只提醒一次；說「有什麼變動」AI 跑 `kb changes` 列出來、說「套用」跑 `kb inventory scan` 記進清冊；Word、Excel、PowerPoint 檔打開再存不算修改。其他 skill 還沒有。對話要開在總資料夾裡；敏感的帳密不要打在對話裡（Claude Code 自己的紀錄與雲端都有）。

## 環境需求

只支援 Windows。要有 Python 3.10 以上，而且 PATH 上打 `python` 要能跑到它（Windows 商店的空殼不算）：守門與備份是 hook，`python` 找不到或跑太久時 Claude Code 會當作沒有 hook，照常放行。

python 壞掉時對話開頭不會有「【wiki-with-willy】」開場段，AI 會說程式沒跑起來並停手；照它說的裝好 python，再關掉 Claude Code 重開。
