## 這是什麼

把客戶既有的資料夾建成 AI 維護的知識庫的 Claude Code plugin：問、答與出處、剛做了什麼、退回、要我決定什麼、資料去了哪。

## 怎麼載入

開發期用 `--plugin-dir` 直接指到這個 repo 的資料夾：

```
claude --plugin-dir "<repo 路徑>"
```

這是開發期的載法，不會安裝到 Claude Code 的 plugin 快取；正式的安裝與升級方式之後補。

## 怎麼用

加資料夾、不讀某夾：在知識庫的對話裡直接說，AI 會先講清楚再做。例如：

- 「把 D 槽的報價也加進來」：AI 請你貼完整路徑，先報有幾份檔、哪些檔名像密碼不會讀，你說好才加。
- 「不要讀公司行政裡的薪資」：AI 問你是不想讓 AI 看到，還是只是用不到，你選了才排除。
- 「客戶案件那個資料夾不要了」：AI 問你是以後不讀還是要刪檔；拿掉只是不讀，檔案不動，說「退回上一版」救得回。
- 「你現在讀哪些資料夾」：AI 列出登記的資料夾和不讀的夾。

加進來的資料夾會入清冊（`.system/inventory.json`），記每份檔在哪、多大、內容指紋。每次開對話，開場會先快速比一次，有變動就多一行「變動：新增 N、修改 N、不見 N」；搬動、改名、多一份一樣的不算變動。某個資料夾這台電腦找不到（外接硬碟沒插、搬走了），開場報一次，其他照常。Word、Excel、PowerPoint 另存但內容沒變，不算修改。

### 整理成卡

每份檔會整理成一張檔案卡，放在 `檔案索引/`（夾的結構照原檔），卡上寫這是什麼、重點、日期與數字、提到的人與單位，每點標原檔的頁數或列數，還有一條連結點了開原檔。總資料夾最上層的 `總目錄.md` 列出全部的卡，可以摺疊（Obsidian 也看得懂）。

- 加完資料夾 AI 會問「要我現在整理成卡嗎？」；之後開對話時開場看到有變動，AI 先說一聲有幾份、大約多久（要停按停止），整理完再回答你問的，答案用整理後的資料。一次超過 20 份會先用現有資料回答，再問你要不要整理。
- Word、Excel、PowerPoint、純文字（含 Big5 舊檔）由程式抽字，不用另外裝東西。PDF 要裝選配元件 pypdfium2（見環境需求）：有文字的頁由程式抽字，掃描頁轉成圖給 AI 看（最多 20 頁，更多的卡上標「部分」）。圖片檔由 AI 直接看原檔。
- 讀不到的檔（有密碼、`.doc` 這種舊格式、只在雲端還沒下載）不做卡，記在 `系統/待處理.md`，寫了怎麼處理。檔名像密碼或金鑰的檔不讀、不做卡。
- 你刪掉的檔，AI 會問「是你刪的嗎？」，你明確說是才把卡拿掉，說「退回上一版」救得回；不是刪的，從資源回收筒或雲端找回來就好。檔案搬到別夾，卡會跟著搬。
- 卡上只記身分證、帳號這類個資的「種類」，不抄號碼；統編、電話預設也只記種類。哪些只記種類、哪些整份不整理，在客戶設定檔第三節改。

### 客戶設定檔

`系統/客戶設定檔.md` 記這個客戶管哪幾類東西、每種文件要記什麼、哪些不整理、AI 怎麼回答你，六張表：

- **型別**：一類一列（例如「案子 事」「客戶 對象」「廠商 對象」），每一類會變成知識庫第一層的一個資料夾。
- **卡型與段落**：報價、合約、會議紀錄……每種卡寫哪些段；「必出現」打 ✓ 的段，原檔沒寫時卡上寫「未知」。
- **不整理與敏感**：哪些資料只記種類不抄值；哪些種類的檔整份不整理成卡（AI 讀了才認得出種類，要保證不讀請說「不要讀 X」）。
- **每類最想知道什麼**：每一類的綜合卡除了現況、紀事、推算，還固定寫哪些段（新加的型別先填一組預設）。
- **關於你**：公司與你本人的名字與別名；AI 認得是你，不會替你自己寫一張綜合卡。
- **偏好**：怎麼回答你、怎麼做東西給你（「回答先講結論」「日期帶星期」），最多 10 條、合計 400 字；每次開對話都會帶進來。只管回答，卡上照原檔寫。

建置前服務人員跟客戶談完，打開這個檔填好前三張表（來源與日期兩欄可以留空），在終端機跑 `kb profile apply`，第一層就會多出型別的資料夾。之後客戶自己改這個檔，下次開對話 AI 會先講改了什麼、問要不要套用，說好才套用。在檔案總管自己建的第一層夾，開場會提醒到設定檔補一列；拿掉一列時，那個型別夾是空的就一起拿掉；夾裡還有東西時那一列拿不掉，要先搬走。套用後說「退回上一版」，設定檔會回到套用前，套用時建的資料夾是空的就一起拿掉（裡面有東西就留著，AI 會說）。

### 實體與綜合卡

檔案卡會掛上它講到的案子、業主、廠商這類（實體）。同一件事有兩份以上的檔，AI 問過你名字對不對，就在 `<型別>\<名稱>\<名稱>.md`（例如 `案子\信義王\信義王.md`）寫一頁現況：現在怎樣、發生過什麼、算出來的數字，每句點得回是哪張檔案卡。之後新檔進來掛上同一件事，AI 整理時會跟著改這一頁，回答最後說改了什麼。

- 設定檔第四節決定每類多寫哪些段（案子預設多寫時程、金額）；第五節「關於你」填公司與你本人的名字，檔案裡出現時 AI 知道是你，不會替你自己寫一張。
- 設定檔沒有的類別（例如還沒有「廠商」），AI 會說有幾份看起來是那一類，要的話在第一節加一列。
- 在檔案總管把實體夾改名、把綜合卡改名、或刪掉整個夾，下次開對話開場會多「實體夾有變」，AI 問你一句：跟著改名還是改回來；刪掉的是不要了還是刪錯了（刪錯了先從資源回收筒還原，沒有的話 AI 照檔案卡重寫一張）。

### 日程

哪天要做什麼，直接在對話裡說：「9/25 下午有個會」「答應王先生 10/10 前給報價」「交屋改 12/10」「第二期款付了」「信義王結案了」「大安陳先暫停」。AI 會記進日程（note），日期換算完會複述給你看。整理檔案卡時讀到的日期（下次開會、付款期限、交屋日、合約寫的工期）也會自動加進來，標〔推測〕，回答最後說加了哪些；已經有卡的檔，說「把日期也整理進日程」就補抽（卡重做後也會再抽一次）；你說「那個會取消了」「交屋改 12/10」就改成你說的。原檔改版後，AI 會照新版更新推測的；你說過的跟新版不同時，AI 問你用哪個。

- 每次開對話，開場印一行「日程：逾期 1、7 天內 3」（0 的不印，全 0 整行不印）。到期與承諾過了還沒做算逾期，AI 會在回答最後問你完成了沒；會議與提醒過了就算已過去，不追。
- `系統\日程.md` 列逾期、今天、接下來 7 天、之後與過去 30 天，加一張時程圖（案子的期間畫成條、日期畫成點；擱置與超過預計結束的期間另畫一段）。這個檔由程式產生，改了會被覆蓋。
- 案子有狀態：進行中（預設）、結案、擱置。AI 讀到驗收或尾款收清這類證據時問你一句要不要記成結案，你說是才改；說還沒，同一份依據不再問。結案時它還沒結束的期間一起結束。
- 「把剛才的答案記下來」、「那份密碼檔可以讀」這版還記不起來，AI 會明說、不會假裝記下。

### 改規則

設定檔不用自己打開改，直接在對話裡說（note）：

- 「多一個廠商類，水電、木作、系統櫃那些」：AI 加一類、建 `廠商` 資料夾，告訴你記成「對象」。
- 「工班改叫師傅」：AI 先列會跟著改的實體、卡與資料夾，問你一次，你選了才改；夾、綜合卡、檔案卡一起改名。兩類併成一類、刪一類也是先列影響再問，要你明確選才做。
- 「請款單不用整理」：記進第三節，之後讀到請款單不做卡。
- 「回答短一點，先講結論」「跟我講日期都要帶星期」：記成偏好，下次開對話開始照做（這個對話裡也會照做）。

改完不對，說「退回上一版」：設定檔回去，改了名或搬過的資料夾也會改回來；資料夾回不去時（例如原來的名字已經有別的夾）什麼都不動，AI 會說原因。你自己在設定檔裡改了還沒套用時，AI 會先問要不要套用，不會蓋掉你改的。

### 改知識

案子的事實、決定與糾正，直接在對話裡說（note）：

- 「內湖李那案改用系統櫃，不做木工了」：記成一條口述，下次整理時內湖李的綜合卡現況改成系統櫃、紀事多一行，出處點得回你哪天說的。改既有的說法時，舊的那條標成被取代、不會記兩條。
- 「你記的單價有誤，磁磚是每坪 8500 不是 5800」：AI 先對原檔。卡抄錯了就標成要重做，下次整理照原檔重寫；原檔本來就寫 5800，就記下你說的 8500，綜合卡兩個都寫、各帶出處。客戶說的不會寫進檔案卡。
- 「這份報價是大安陳的，不是內湖李的」：改掛到大安陳，兩個案子的綜合卡下次整理都會跟著改。
- 「王先生大家都叫他王董」：記成別名，之後讀到王董就掛到王先生。王董之前被當成另一個人登記了，AI 會問是不是同一個、要不要合併。
- 「合約.docx 是舊的，別信」：記成裁示（`系統\裁示.md` 看得到），綜合卡現況不再引用它；之後合約換了新版，AI 會問「現在可以信了嗎」。「信義王的報價以口述為準」也是裁示；「以後都這樣」的話是改規則，不是裁示。

改錯了說「退回上一版」就回去。

### 問資料

問自己的案子、檔案、數字、日程，直接在對話裡問（answer）：

- 「內湖李那案現在進行到哪了？」：AI 讀內湖李的綜合卡、你說過的事、日程回答，每句結尾一個短標（〔報價第二版，第 3 頁〕〔你 10/20 說的〕）；你說過「以口述為準」的先講你說的。
- 「大安陳的報價總共多少？」：先給一句粗估，接著逐份回原檔核對，最後附程式加總的逐筆表；核對時發現卡抄錯了會標成要重做，兩份原檔寫法不同會兩邊都講、記進待處理。你說過別信的那份不算進去。
- 「今年我總共報了幾次價？」：照文件日期列今年的卡，改過名的舊卡型（估價單）一起算，回答講算了哪幾種、有幾份沒寫日期。
- 「你最近幫我改了什麼？」：只講有改動的那幾句、改了什麼；「上次我問王宅你怎麼說」也查得到。
- 「有沒有要我確認的？」：照程式排好的問題先問最多 3 件，其餘在 `系統/待處理.md`。

answer 只讀；要把剛才算好的答案留下來，說「把剛才的答案記下來」（note 記成一筆推算，整理時寫進綜合卡，依據的檔改了會標要重算）。開場有新檔時先整理再回答；整理中按了停止，這個對話就不再自動整理，下次開對話會說「還有 N 份沒整理完」接著做。

### 終端機指令

服務人員在終端機可以直接跑（前綴是開場那行印的 kb 指令）：

- `kb changes`：跟清冊上次掃描比，列新增、修改、搬動、不見的檔名；只看不改。`--all` 列全部，`--quick` 走開場那條快的路。
- `kb inventory scan`：全掃一次，把變動套進清冊；寫前先備份，說「退回上一版」救得回。`--source <別名>` 只掃一個來源。原檔不見的會記進待處理，找回來自動關掉。
- `kb cards todo`：列還沒有卡、該重做、該搬的卡與讀不到、原檔不見的份數；只看不改。`--json` 全列。
- `kb cards sync`：原檔搬了，卡跟著搬；`kb cards drop <編號>`：原檔已刪，拿掉它的卡；`kb cards index`：重寫 `總目錄.md`。
- `kb cards skip <編號> --kind <種類>`：記成依客戶設定檔不整理（種類要在設定檔第三節是「不整理」），有卡的拿掉。
- `kb cards list`：列卡，`--type <卡型>`（可重複）、`--year <YYYY>`、`--entity <名稱>`（可重複）、`--source <別名>` 可疊加；另列庫裡實際有的卡型與份數（設定檔沒有的標出來）、沒寫日期的份數；只看不改。
- `kb lookup <名稱或別名>`：查一個案子、人或公司：綜合卡、掛的檔案卡（原檔改過、你說別信的標出來）、口述、裁示、推算、日程、還沒整理的份數；沒登記的名字列提到它的卡；只看不改。
- `kb tally --row "<編號> <數字> [位置]"…`：加總（收千分位、小數、負號、「萬」），印逐筆表、筆數、合計、平均；只看不改。
- `kb cards redo <編號>`：卡讀錯原檔，標成要重做（下次整理照原檔重寫）；`kb cards mount <編號> --entity <名稱>`：卡掛錯實體，改掛，兩邊的綜合卡下次整理跟著改。
- `kb profile check`：看客戶設定檔改了什麼、第一層有沒有不在型別表的夾；只看不改。`kb profile apply`：套用，建缺的型別夾；寫前先備份。
- `kb profile show|add|remove|type`：看六節（`--json` 給欄位與指令範本）、加或改一列、拿掉一列、型別改名／合併／拿掉（`type … --check` 只算影響不動手）；寫前先備份，設定檔有手改還沒套用時拒絕。
- `kb convert <編號或路徑>`：把一份檔抽成純文字暫存檔（`.system/temp/`，24 小時後清掉），終端機不印內容；PDF 的掃描頁另轉成 PNG，圖片只印路徑。
- `kb pending list|add|resolve|dismiss`：看、處理 `系統/待處理.md` 的事；`kb pending add --kind conflict --card <編號> --card <編號> --text "<一句>"`：記一件兩份原檔寫法不同的（同一對只記一次）。
- `kb entity add|confirm|rename|merge|remove|rebuild|clean|list|render`：登記、確認、改名、合併、移除實體，重寫被刪的綜合卡、清掉放錯的綜合卡、列出實體、重寫綜合卡的快取欄；寫前先備份，說「退回上一版」救得回（程式改了的夾名也會改回來）。改名與合併會連日程、口述、裁示裡掛的名稱一起換。`kb entity alias <名稱> --add|--remove <別名>`：加或拿掉別名（撞到已登記的實體會拒絕、改問合併；拿掉時列出內文提到那個別名的卡）。
- `kb entity progress <名稱> <進行中|結案|擱置>`：案子這類「事」的狀態，結案連帶結束它的期間；`kb entity suggest-close <名稱> --evidence <f-…>`：記一條「看起來結案了」等客戶答。
- `kb agenda add|edit|done|cancel|reopen|recheck|list|render`：加、改、完成、取消、重開日程，記下原檔新版的寫法，列出，重寫 `系統/日程.md`；寫前先備份，說「退回上一版」救得回。`kb agenda list --from <日期> --to <日期> --entity <名稱>`：只列那段期間、那個實體的。`kb asks`：只看，列出 AI 該問你的事。
- `kb statement add|withdraw|list`：記一條客戶口述（`--replaces` 改舊的）、收回、列出；`kb ruling add|remove|recheck|list`：記一條裁示（口述為準、不採用）、收回、原檔新版看過了照舊、列出（最後一行是條數），重寫 `系統/裁示.md`。都先備份，說「退回上一版」救得回。
- `kb finding add|withdraw|list`：記一筆推算（`--entity`、`--text` 結果、`--how` 算法、`--basis` 依據的卡，`--replaces` 取代舊的）、收回、列出（依據變了的標「待重算」）；寫前先備份。
- `kb journal recent`：最近幾段工作日誌，每段帶你說的、結果、做了、改了；`--changed` 只列有改動的、`--find <詞>` 找說過的、`--since <YYYY-MM-DD>` 某天以後，可疊加。

搬檔、改名、資料夾搬家、重建知識庫這版還做不到，AI 會說怎麼自己做。

## 狀態

建置中。0.15.0 有守門、事務層、骨架與來源登記、工作日誌、開場注入與核心規則、第一個 skill manage、清冊：`kb init` 建總資料夾，`kb folders add|exclude|list` 登記客戶的資料夾與不讀的夾；知識庫裡開對話時，客戶原檔只讀、排除的夾不讀、檔名像密碼或金鑰的檔不讀（客戶說可以才讀）、`kb.py` 不用按允許；每句話一個回合，AI 改綜合卡、檔案索引、AI 產出前先備份，說「退回上一版」就退，AI 產出會登記；一句話改超過 10 張綜合卡會先停下來問；對話裡打的帳密不會原樣記進系統檔。每句話問了什麼、AI 答了什麼、做了什麼、改了哪些檔記進 `系統/工作日誌/`（建知識庫、加資料夾、退回這些程式自己做的事也有一段），問「最近改了什麼」由腳本 `kb journal recent` 讀。每個對話一開始 AI 就拿到十四條核心規則與 `kb.py` 的位置，摺疊後也會重新拿到；python 沒跑起來時 AI 會說程式沒啟動並停手。在對話裡說「把 D 槽的報價也加進來」「不要讀私人那夾」「那個資料夾不要了」「私人那夾還是讀好了」「現在讀哪些資料夾」就會做（manage）；搬檔、改名、搬家、重建還做不到。加進來的資料夾會入冊，每次開對話先快速比對、開場印「變動：新增 N、修改 N、不見 N」，找不到的資料夾只提醒一次；說「有什麼變動」AI 跑 `kb changes` 列出來、說「套用」跑 `kb inventory scan` 記進清冊；Word、Excel、PowerPoint 檔打開再存不算修改。客戶設定檔（`系統/客戶設定檔.md`）記型別、卡型與段落、不整理與敏感三張表，`kb profile apply` 套用並建型別夾，客戶改了開場會問要不要套用；製卡照設定檔的卡型與段落，設定成不整理的種類不做卡。檔案卡會掛上它講到的案子、業主、廠商（`.system/entities.json`）；同一件事有兩份以上的檔、AI 問過名字，就在 `<型別>/<名稱>/<名稱>.md` 寫一頁現況，新檔進來跟著改；設定檔第四節決定每類多寫哪些段，第五節「關於你」填公司與本人就不會替你自己寫一張；在檔案總管改實體夾名、刪夾，下次開對話 AI 會問一句。AI 要你決定的事會在回答末尾列成選項，回編號、字母或直接說意思都可以；會刪東西的只回「好」不算，AI 會再問一次。在對話裡說「9/25 下午有個會」「交屋改 12/10」「信義王結案了」就會記進日程（note，這版只記日程與案子狀態，其他記事類的話 AI 會明說還記不起來），開場印「日程：逾期 N、今天 N、7 天內 N」，`系統/日程.md` 有清單與時程圖。在對話裡說「9/25 下午跟王先生看磁磚」「交屋改 12/10」「第二期款付了」「信義王結案了」會記進日程與案子的狀態（note），製卡時讀到的日期也會自動加進來並標推測，開場印逾期與這週要做的，`系統/日程.md` 有清單與甘特圖。說「回答短一點」「多一個廠商類」「工班改叫師傅」「請款單不用整理」也會記進客戶設定檔（偏好會在每次開對話時帶進來；改名、合併、刪型別先列出影響、你明確選了才做，退回時資料夾也會改回去）；開場有新檔時先整理、整理完再回答。說「內湖李改用系統櫃了」「你記的單價有誤」「這份報價是大安陳的」「王先生大家都叫他王董」「合約.docx 是舊的，別信」也會記（口述進清單、綜合卡下次整理時改並標出處；糾正先對原檔分出錯在哪；別名；只有這一件的裁示記在 `系統/裁示.md`，原檔改版時 AI 會問還要不要照舊）；密碼檔可以讀這版還做不到。問「內湖李現在怎樣」「今年報價總共多少」「你最近改了什麼」由 answer 回答（材料由 `kb lookup`、`kb cards list` 給齊，數字回原檔核對、`kb tally` 加總）；說「把剛才的答案記下來」記成推算。produce、lint 這些 skill 還沒有。對話要開在總資料夾裡；敏感的帳密不要打在對話裡（Claude Code 自己的紀錄與雲端都有）。

## 環境需求

只支援 Windows。要有 Python 3.10 以上，而且 PATH 上打 `python` 要能跑到它（Windows 商店的空殼不算）：守門與備份是 hook，`python` 找不到或跑太久時 Claude Code 會當作沒有 hook，照常放行。

要讀 PDF 請 `pip install pypdfium2`（選配，沒裝 PDF 會列在待處理）。

python 壞掉時對話開頭不會有「【wiki-with-willy】」開場段，AI 會說程式沒跑起來並停手；照它說的裝好 python，再關掉 Claude Code 重開。
