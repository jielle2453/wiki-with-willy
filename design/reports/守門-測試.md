  ```
  → allow 知識庫腳本
  ```
  有擋住的對照組：`$(…)`、反引號、換行串接、`2>/dev/null` 都回 pass。
- **kb.py 的 allow 涵蓋所有參數與子命令**（中，設計層）：現在只有 `version` 與 `guard decide`，兩個都唯讀，所以沒有問題。以後新增會寫檔或收路徑參數的子命令，就會不經區表直接 allow。建議在 spec／CLAUDE.md 寫下不變式：kb 子命令自己守區表。或者改成子命令白名單。
- **`CLAUDE_PLUGIN_ROOT` 優先於 `__file__`**：設成別處時，該處的 `scripts/kb.py` 拿到 allow（已重現）。這個環境變數由 Claude Code 設定，AI 改不到，所以只列為低風險。
- **ledger 只清 `\t\r\n`**（低，未重現）：`\x0b`、`\x85`、U+2028 等字元可能讓用 `splitlines()` 的讀者看到多出來的列。lint 讀 ledger 時要用 `split("\n")`。
- **ReDoS**：粗測 2–4 萬字的長輸入，最慢 0.51 秒，遠低於 10 秒逾時，沒有發現問題。
