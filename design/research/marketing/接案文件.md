**給客戶看的版本**在 Claude Docs：[AI 知識庫代建服務說明](https://claude.ai/code/artifact/b815e2cb-ad6b-464f-9022-1bc7b9700748)（說明書一個分頁、「服務合約（草稿）」一個分頁，可匯出 Word／PDF）。客戶版經產品負責人刪改過，以 Docs 上的為準；這份是內部的完整紀錄與理由。

### 內部完整清單（32 題）與對 plugin 的影響

客戶版沒有收的題目（簡稱、常往來的人、案子、掃描檔、舊格式、Google 文件、回答偏好、筆記要多記什麼等），訪談時要不要另外補問還沒定（第六節）。

標示：✅ plugin 已有地方處理；⚠️ 部分；❌ 還沒實作或沒有欄位。

**1. 電腦環境（建置前先問）**

| # | 問題 | 影響 plugin 哪裡 | 沒問到會怎樣 |

| 1.1 | 電腦是自己的還是公司的？能自己裝軟體嗎？ | build-setup 第 1 步要裝 Python、MarkItDown、pdfplumber；程式是主要做法（決策 #7） | 當天裝不了，只能用備用做法，慢又不準 |
| 1.2 | 用 Windows 嗎？哪一版？ | 第一版只支援 Windows | Mac 沒測過 ❌ |

## 五、驗收方式

**討論過程：** 我們寫固定題（不知道答案，不可行）→ 客戶自選 10 題（容易出到範圍外）→ 題型範本讓客戶填 → 功能驗收、客戶當場出題 → **最後決定不出題，磨合期內依功能清單確認**。

| # | 功能 | 達成的意思 |
|---|---|---|
| 1 | 找到檔案的實際位置 | 指出實際位置，點連結能打開 |
| 2 | 回答附出處 | 附上出自哪份檔案，點得開 |
| 3 | 找不到會說找不到 | 不編造答案 |
| 4 | 新檔案自動跟上 | 新增或修改的檔案，開新對話後問得到 |
| 5 | 刪除前先問 | 原檔被刪時先問客戶 |
| 6 | 糾正會記住 | 之後的對話照糾正後的回答 |
| 7 | 敏感資料不說出來 | 只指出在哪份檔案 |
| 8 | 讀不到的檔案有交代 | 建置報告列出份數與原因 |
