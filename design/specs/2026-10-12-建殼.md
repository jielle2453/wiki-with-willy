## 目的
建立 repo 與 plugin 的最小殼：Claude Code 載得進、測試跑得綠、流程工具就位（CHANGELOG、CLAUDE.md 地圖、預算測試、版號對齊測試、唯一 CLI 入口）。沒有任何功能。對應 backlog B-001。這一題沒有使用者時刻，是後面每一題的地基。

## 要做的事

### 1. manifest 與根目錄文件
- `.claude-plugin/plugin.json`：見「資料與介面格式」。
- `LICENSE`：MIT，著作權人寫 `wiki-with-willy contributors`，年份 2026。
- `README.md`：三段。這是什麼（一句）；怎麼載入（`claude --plugin-dir "<repo 路徑>"`，說明這是開發期載法）；狀態「建置中，尚無功能」。給服務人員與使用者看，中文。
- `CLAUDE.md`：給改 repo 的 Claude。三節：
  1. 原始碼地圖：目錄表，殼有的檔寫用途，架構第九節計畫中的目錄標「尚未」。
  2. 改完要做的事：跑 `python -m unittest discover tests`；動過 `plugin.json` 或 `hooks/` 要跑 plugin 驗證；bump 版號的那個 commit 要同時寫 CHANGELOG。
  3. 不准：不寫 plugin 絕對路徑進任何狀態檔或設定；核心只用標準函式庫；不 push、不 bump，除非設計 session 說發行。
  開頭三行照 conventions：日期、給誰看、何時更新。
- `CHANGELOG.md`：開頭三行說明（一版一段、最新在上、bump 的那個 commit 同時寫這裡）。第一段 `## 0.1.0 — 2026-10-12`，四個項目：改了什麼、為什麼、commit（實作時填 hash）、spec（`design/specs/2026-10-12-建殼.md`）。
- `.gitattributes`：`* text=auto eol=lf`。
- `.gitignore`：`__pycache__/`、`*.pyc`、`.claude/settings.local.json`、`*.tmp`。不排除 `design/`。

### 2. 權限
- `.claude/settings.json`：見「資料與介面格式」。只放行測試與 `kb.py`。

### 3. 唯一 CLI 入口
- `scripts/kb.py`：唯一入口。開頭 `sys.dont_write_bytecode = True`、`sys.stdout.reconfigure(encoding="utf-8")`。不動 `sys.path`：以 `python scripts/kb.py` 執行時 `scripts/` 自然在 `sys.path[0]`，直接 `from kb.cli import main`。
- `scripts/kb/__init__.py`：空。
- `scripts/kb/cli.py`：`argparse` 主程式。子命令註冊表 `COMMANDS = {名稱: (模組, 一句說明)}`，`--help` 列全部子命令與說明。全域參數 `--json`。殼只註冊一個子命令 `version`。未知子命令讓 argparse 回 exit 2。
- `scripts/kb/version.py`：`run(args) -> int`。讀 `plugin.json` 印 `wiki-with-willy 0.1.0`；`--json` 印 `{"name": "...", "version": "..."}`。
- `scripts/kb/_lib/__init__.py`：空。
- `scripts/kb/_lib/paths.py`：`plugin_root() -> Path`（從 `__file__` 往上找到含 `.claude-plugin/plugin.json` 的目錄）、`read_manifest() -> dict`。
- `scripts/kb/_lib/io.py`：`read_json(path, default=None)`、`write_json_atomic(path, data)`（UTF-8、`ensure_ascii=False`、縮排 2、LF、先寫 `.tmp` 再 `os.replace`）、`read_text(path, encoding)`、`write_text_atomic(path, text)`（UTF-8、LF）。全部帶 `encoding=`。

### 4. 設定
- `config/defaults.json`：`{"schema_version": 1, "_why_schema_version": "每個設定檔都帶版本，升級時遷移（D-014）"}`。只有這一鍵。

### 5. 測試
全部 `unittest`，`tests/__init__.py` 空。
- `tests/test_kb_cli.py`：用 `subprocess` 跑 `python scripts/kb.py`：`--help` exit 0 且輸出含 `version`；`version` 輸出等於 `wiki-with-willy 0.1.0`；`version --json` 可 `json.loads` 且 name、version 與 `plugin.json` 一致；`nosuch` exit 2。
- `tests/test_lib_io.py`：`write_json_atomic` 後 `read_json` 一致，含中文；檔案是 UTF-8 無 BOM、LF；寫失敗不留 `.tmp`（用不存在的目錄驗）。
- `tests/test_version_sync.py`：`plugin.json` 的 version 等於 CHANGELOG 第一個 `## X.Y.Z — ` 的版號。
- `tests/test_budget.py`：常數照 D-070（見下表）。量 `skills/*/SKILL.md` 的 description 字數與本文行數、`rules/core.md` 行數與字數、`skeleton/CLAUDE.md` 行數與字數、`skills/*/references/*.md` 行數。檔案不存在就 `skipTest`，存在就量。附一個內建自測：對 `tests/fixtures/budget/too_long_SKILL.md` 量，必須判超標。
- `tests/test_repo_hygiene.py`：對 `git ls-files` 列出的 `.py` `.md` `.json` 檔檢查：UTF-8 無 BOM、LF、檔尾一個換行；排除 `design/`。另檢查這些檔（排除 `design/`、`README.md`）不含 `C:\\Users` 或 `C:/Users` 字串。

### 6. git
- 順序：先寫 `.gitattributes` 與 `.gitignore`，再 `git init`（預設分支 `main`）、`git add -A`，然後才跑測試；`test_repo_hygiene.py` 靠 `git ls-files`，沒 init 會紅。測試全綠才 commit。
- 第一個 commit 就是這一題的全部內容加既有的 `design/`。訊息第一行 `建殼: repo 與 plugin 最小殼`，結尾 `Spec: design/specs/2026-10-12-建殼.md` 加 Co-Authored-By。author 用 `git -c user.name="實作:建殼" commit`。
- 這一題直接在 `main`，是 conventions 三「第一個 commit 只有殼」的初始化例外；之後每題開 `spec/<題目>` 分支。
- 不 push、不 tag。

### 不建的東西
不建空目錄（`rules/`、`skills/`、`hooks/`、`skeleton/`、`templates/`、`agents/`、`commands/`），CLAUDE.md 地圖標「尚未」。沒有 `hooks.json`，plugin 沒有 hook 也載得進。

## 資料與介面格式

`.claude-plugin/plugin.json`：

```json
{
  "name": "wiki-with-willy",
  "version": "0.1.0",
  "description": "把客戶既有的資料夾建成 AI 維護的知識庫：問、答與出處、剛做了什麼、退回、要我決定什麼、資料去了哪。",
  "author": { "name": "wiki-with-willy" },
  "license": "MIT",
  "keywords": ["knowledge-base", "wiki", "繁體中文"]
}
```

`.claude/settings.json`：

```json
{
  "permissions": {
    "allow": [
      "Bash(python -m unittest:*)",
      "Bash(python scripts/kb.py:*)",
      "Bash(python \"scripts/kb.py\":*)"
    ]
  }
}
```

`kb.py` 介面：

| 指令 | stdout | exit |
|---|---|---|
| `python scripts/kb.py --help` | 用法、子命令清單（含 `version` 與一句說明）、`--json` 說明 | 0 |

| `python scripts/kb.py version --json` | `{"name": "wiki-with-willy", "version": "0.1.0"}` | 0 |
| `python scripts/kb.py nosuch` | argparse 錯誤到 stderr | 2 |
