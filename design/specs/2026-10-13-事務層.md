## 目的
守門（v0.2.0）已放行 AI 寫綜合卡、檔案索引、AI 產出，但寫了退不回、成品沒人登記。這題補上原則 2 的機器保證：筆記必經備份、成品必經登記，加上「退回上一版」與「一句話改太多張就停」。對應六個面的「剛做了什麼」（部分）、「退回」。工作日誌不在本題（另題）。

## 決策
D-074 回合、備份與退回；D-075 大改動攔截；D-076 清冊最小版；D-011（含 2026-10-13 補）退回時的成品；D-046（含 2026-10-13 補）路徑表：綜合卡、檔案索引、AI 產出都回合備份，指令寫前兩區擋；D-056 保留期（本題不清理）；D-027 語言分層；D-014 schema_version；D-019 不寫 plugin 路徑。事故 I-027、I-028、I-035、I-038、I-039、I-041、I-018、I-055。

本題釐清、不改 D 的點：
- `kb.py` 子命令由模型呼叫時拿不到 session_id，所以 CLI 用 `.system/turns/current.json`（最近一句話的回合）；兩個對話同開時 CLI 可能指到另一個 session 的回合，記 B-019，collab 題再處理。hook 有 `session_id`，備份一律進正確的回合。
- 退回時刪成品也走同一個備份函式，再退一次可以救回，受 D-056 保留期限制；所以不說「救不回」。流程是 revert（只列、不刪）→ 客戶說刪 → `delete-outputs`（第一輪 H1 後定）。
- 守門出錯已定 deny；本題加「備份失敗也 deny」：備不了就不准寫（fail closed，I-055 同理）。

### 2. 回合 `scripts/kb/_lib/turn.py`（新）

### 6. CLI
- `kb versions list [--n 5]`：由新到舊每回合一行：代號、時間、問（prompt_head）、修改／新增／刪除檔數、成品份數、`（已退回）`、`（這一次）`；每回合底下列路徑最多 15 行。`--json` 印陣列。沒有回合印「還沒有任何改動紀錄」。
- `kb versions revert [代號] [--delete-outputs]`：
  1. 目標是最近一個「沒退過且 manifest 非空」的回合；給了代號但不是它 → 印「只能從最近一次開始退：<代號>」，exit 3。沒有可退的 → 印「沒有可以退回的改動」，exit 3。
  2. 退回動作本身的回合：`turn.current(vault)`；每個要動的檔先 `backup` 進這個回合（存在→modify、要刪→delete、要移除新增檔→modify）。
  3. 還原：manifest 由後往前，`modify`／`delete` 從 `files/<rel>` 複製回去；`create` 的檔若還在就刪，刪後父夾空就移除空夾（只移到型別夾那層，型別夾本身不刪）；但 `create` 且在 Z3 的檔**沒有 `--delete-outputs` 就不刪**。`files/` 裡找不到備份（保留期清掉）印「無法還原 N 檔」。
  4. 成品：只算「inventory `created_turn` 是這回合**且**這回合 manifest 記 `create`」的（第一輪 M4）。沒 `--delete-outputs`：status 改 `turn_reverted`，清單印出來，最後一句「這 N 份成品先留著；要刪跟我說，我用 delete-outputs 刪」。有：刪檔（先 `backup` action `delete`）、status 改 `deleted`。
  5. 在目標回合夾寫 `reverted.json` `{"time", "by_turn"}`。
  6. 印「已退回 <代號>（問：…）：還原 N、移除 M、成品 K 份留著／刪了」，`--json` 印同內容。
  7. 退回動完後對每個碰到的 Z3 路徑對帳清冊：檔在就該 location 最新一筆 status 改 `active`，不在就改 `deleted`（第一輪 M3）。
- `kb versions delete-outputs [代號]`（第一輪 H1）：刪「已退回的回合」裡 status 還是 `turn_reverted` 的成品。沒給代號取最近一個這樣的回合；給了但那回合沒退過或沒有可刪成品 → 印「<代號> 沒有可刪的成品」exit 3。每份先 `backup`（action `delete`）進目前回合再刪，status 改 `deleted`，印「已刪 N 份成品：…」。這是「退回 → 客戶說刪 → 刪」的第二步，revert 本身不再問「確定嗎」。
- `kb turn current`：印目前回合代號、問、已備份檔數、`approved`；`--json`。
- `kb turn approve`：`turn.approve`，印「這一題解除綜合卡張數上限」。
- `cli.py` `COMMANDS` 加 `versions`、`turn`。

## 資料與介面格式

### `.system/turns/<session_id>.json` 與 `current.json`
```json
{"schema_version": 1, "turn": "20261013-153012-a1b2", "session_id": "a1b2c3d4-…", "started": "2026-10-13T15:30:12", "prompt_head": "幫我把信義王的現況改成已完工", "approved": false}
```
`current.json` 同格式，是最近一次 `start` 的內容。sid 做檔名前把非 `[A-Za-z0-9._-]` 換成 `_`。

### `.system/versions/<turn>/`
- `turn.json`：`{"schema_version": 1, "turn", "session_id", "started", "prompt_head"}`；是退回動作的回合另有 `reverted_turn`（第二輪 R2-4）。
- `manifest.jsonl`：一行一檔 `{"path": "案子/信義王/信義王.md", "action": "modify", "time": "2026-10-13T15:30:40"}`；action 三值 `modify`、`create`、`delete`。
- `files/<path>`：modify 與 delete 的舊版。
- `reverted.json`：`{"time", "by_turn"}`，退回後才有。

### `.system/inventory.json`
```json
{"schema_version": 1, "entries": [
  {"id": "out-3f9a1c2e", "origin": "ai_output",
   "locations": ["file://AI 產出/案子/2026-10-13 信義王 合約草稿.md"],
   "created_turn": "20261013-153012-a1b2", "created": "2026-10-13T15:31:02",
   "fingerprints": [{"sha256": "…", "time": "2026-10-13T15:31:02", "turn": "20261013-153012-a1b2"}],
   "status": "active"}
]}
```
`locations` 的 `file://` 後面是相對總資料夾的路徑、正斜線（D-021 的可攜 spec）。status 四值 `active`、`turn_reverted`、`deleted`、`superseded`（同位置後來有新成品，第二輪 R2-3）。

### `config/defaults.json`
```json
{"schema_version": 1, "_why_schema_version": "…",
 "big_change_synthesis_max": 10,
 "_why_big_change_synthesis_max": "同一句話由 AI 自己決定修改的既有綜合卡張數上限，到了就停下來問（D-075、I-028）；客戶同意後 kb turn approve 解除這一回合"}
```
