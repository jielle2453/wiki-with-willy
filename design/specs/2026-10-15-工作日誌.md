## 目的
六個面的「剛做了什麼」現在只有回合帳（`.system/versions/`，30 天後清），客戶沒有一個看得懂、永久留著的地方知道「我問過什麼、AI 答了什麼、改了哪些檔」。這題把它做出來：每句話一段，問由 UserPromptSubmit 記、結果由 Stop hook 記、做了與改了從回合帳來；程式自己做的事（建知識庫、加資料夾、退回）也有一段。順便收 B-027（`kb turn redact`）與 B-028 第 2 項（問截到 80 字）。

## 決策
D-082 JSON 為真住 `.system/journal/`；D-083 一行分兩次寫、Stop 讀 `last_assistant_message`、中斷補記、一回合只收第一次 Stop；D-084 「做了」程式地板加 AI 覆寫；D-085 程式段由 CLI 自己寫、對話裡叫的併進回合；D-086 問 200 字、多遮不改、所有人與模型的文字欄都遮、`kb turn redact` 帶句子；D-061 結果截斷（300 字、結論或摘要段優先、「全文見對話」）；D-065 五行、每月一檔、永久留、程式操作也一段、「最近改了什麼」讀「做了」；D-067 渲染檔頂端三行、格式住程式、範例在 fixtures；D-031（含 2026-10-15 補）；D-081 遮值；D-074 回合；D-027 語言分層；D-014 schema_version；D-004 數字住 config。事故 I-035、I-046、I-084、I-089、I-097、I-098。

本題釐清、不改 D 的點：
- md 裡段落**最新在上**（客戶開檔是要看剛才的事），jsonl 是追加順序。
- 一行的「月」由回合代號的日期決定，不是 Stop 的時間：跨月的回合留在開口那個月。
- 「做了」的 AI 覆寫（`kb turn note`）在 Stop 之後叫也生效，會改寫 jsonl 那行；「結果」只收第一次 Stop（D-083）。
- 程式段的「改了」由指令自己給（它知道自己動了什麼），不從 manifest 算：CLI 連續指令共用一個回合，manifest 會累積。
- payload 沒有 `last_assistant_message`（舊版 Claude Code）時結果寫固定句「（這版 Claude Code 沒給最後回答）」，不解析 transcript。
- `stop_hook_active` 不理：我們從不 block，第一次 Stop 就記。
- Stop 時 `turns/<sid>.json` 不存在就什麼都不做，不退到 `current.json`（Stop 一定有 session_id；退到 current 會記到別的對話）。

  1. `result = journal.cut_result(credentials.mask_secrets(last_assistant_message), config journal_result_max)`；payload 沒這個鍵用固定句。
  2. `note = turn 檔的 note`（模型叫過 `kb turn note`），空就 `journal.floor_note(vault, turn_id)`，`note_by` 分別是 `ai`／`program`。
  3. `changed = turn.entries(vault, turn_id)` 的 `{path, action}`。
  4. `journal.complete_turn(vault, turn_data, result, note, note_by, changed, interrupted=False)`，再 `turn.set_done(vault, session_id)`。
  任何例外寫 hook-errors.log（source `stop`），永遠 exit 0、不輸出。開頭照其他 hook：`dont_write_bytecode`、reconfigure、`sys.path.insert`。
- `hooks/turn.py`（改）：決定要開回合之後、`turn.start` 之前，先 `journal.flush_unfinished(vault, session_id)`：`turns/<sid>.json` 存在且 `done` false → 用「（回答被中斷，沒有結果）」當結果、地板句當做了、manifest 當改了，`interrupted=True` 補記那一行。`start` 之後呼叫 `journal.open_turn(vault, turn_data)` 寫這回合的第一次。兩個呼叫各自包 try，失敗寫 hook-errors.log，不影響開回合。一支 hook 最多等一次鎖：`flush_unfinished` 鎖逾時就跳過 `open_turn`（寫一行 log），hook 整支要在 5 秒內。
- 寫 hook 前先讀 `plugin-dev:hook-development`（Stop 的輸入欄位以它為準，payload 欄位名見「資料與介面格式」）；動了 `hooks.json` 收尾跑 `claude plugin validate` 與 agent `plugin-dev:plugin-validator`。

### 2. 日誌 `scripts/kb/_lib/journal.py`（新）
- `JOURNAL_REL = .system/journal`、`RENDER_REL = 系統/工作日誌`。
- `month_of(turn_id) -> "YYYY-MM"`：從代號前 8 碼取；代號解析不了用今天。
- `jsonl_path(vault, month)`、`md_path(vault, month)`。
- `read_lines(vault, month) -> list[dict]`：壞行跳過並寫一行 hook-errors.log（I-046、同 manifest 的做法），不讓整月失效。
- `open_turn(vault, turn_data)`：寫入或換掉 `kind == "turn"` 且 `turn` 相同的那行（upsert），欄位見格式；`done` false。
- `complete_turn(vault, turn_data, result, note, note_by, changed, interrupted)`：同一行 upsert，補 `ended`、`result`、`result_truncated`、`interrupted`、`note`、`note_by`、`changed`、`done` true。
- `update_turn(vault, turn_id, **fields)`：只改給的欄位（`kb turn note`／`redact` 用）；那行不存在就不做、回 False。
- `flush_unfinished(vault, session_id)`：`turns/<sid>.json` 存在且 `done` false 就用中斷固定句、地板句、manifest 補記那行並 `set_done`；沒有就不做。`hooks/turn.py` 在開新回合前叫。
- `record_program(vault, note, changed, command, turn_id=None)`：追加一行 `kind == "program"`；`turn_id` None 就用現在時間組 `YYYYMMDD-HHMMSS-0000`，不碰 `turns/`（`kb init` 用）。
- `floor_note(vault, turn_id) -> str`：manifest 按 `turn.zone_of` 分區、按 action 數：Z1「改了 N 張綜合卡」「新增 N 張綜合卡」「刪了 N 張綜合卡」；Z5 同句型但叫「檔案卡」；Z3「新增／改了／刪了 N 份 AI 產出」；Z7（`.system/`、`.claude/settings.json`、CLAUDE.md）「改了設定與狀態檔」（不數）；其他區「改了 N 個檔」。用「、」接；沒有任何行回「沒有改動」。
- `cut_result(text, max_chars) -> (str, truncated)`：找 Markdown 標題行 `^#{1,6}\s*(結論|摘要)`，有就取那個標題（不含標題行）到下一個同級或更高級標題之間的段；沒有就整段。去掉頭尾空白後取前 `max_chars` 字，有截就加「…全文見對話」。不壓空白（jsonl 存原樣，渲染時才壓）。空字串回（「（沒有文字回答）」, False）。
- `recent(vault, n) -> list[dict]`：從本月往前翻最多 12 個月，收集到 n 行為止，新在前；`kind` 兩種都收。
- `render(vault, month)`：從 jsonl 整檔寫 `系統/工作日誌/YYYY-MM.md`，格式見下；`write_text_atomic`。每個會寫 jsonl 的函式做完都 `render`。
- 鎖：讀改寫 jsonl 整段包 `FileLock(jsonl_path)`；hook 預設 3 秒，拿不到丟 `TimeoutError` 給呼叫端寫 log。jsonl 本身用 `write_text_atomic` 整檔重寫；渲染不在鎖裡（最後一個寫的人渲染的就是最新）。
- 所有從人或模型來的欄位（`prompt`、`result`、`kb turn note` 給的 `note`）寫入前過 `credentials.mask_secrets`；程式段的 `note` 不遮。

## 資料與介面格式

### `.system/journal/YYYY-MM.jsonl`
一行一個 JSON 物件，UTF-8、LF，每行都帶 `schema_version`。兩種 `kind`。

回合行，開口時：
```json
{"schema_version": 1, "kind": "turn", "turn": "20261015-180536-ea64", "session_id": "ea64c3c8-…", "time": "2026-10-15T18:05:36", "prompt": "幫我看 公司行政\\舊檔\\Big5備忘.txt 寫什麼", "done": false}
```
Stop 之後（同一行被換掉）：
```json
{"schema_version": 1, "kind": "turn", "turn": "20261015-180536-ea64", "session_id": "ea64c3c8-…", "time": "2026-10-15T18:05:36", "prompt": "幫我看 公司行政\\舊檔\\Big5備忘.txt 寫什麼", "done": true, "ended": "2026-10-15T18:06:10", "result": "這份是 Big5 編碼的備忘，四行：水電師傅趙師傅電話…", "result_truncated": false, "interrupted": false, "note": "沒有改動", "note_by": "program", "changed": []}
```
`note_by` 兩值 `ai`、`program`；`changed` 每筆 `{"path": "案子/信義王/信義王.md", "action": "modify"}`，action 同 manifest 三值。中斷補記的行 `interrupted` true、`result` 是「（回答被中斷，沒有結果）」。

程式行：
```json
{"schema_version": 1, "kind": "program", "turn": "20261015-180344-0000", "time": "2026-10-15T18:03:44", "command": "folders add", "note": "已登記「客戶案件」（../../來源/客戶案件，15 份）", "changed": [{"path": ".system/sources.json", "action": "modify"}]}
```

### `.system/turns/<sid>.json`（加兩鍵）
```json
{"schema_version": 1, "turn": "…", "session_id": "…", "started": "…", "prompt_head": "…", "approved": false, "note": "", "done": false}
```
