# 安裝、升級與發行
日期：2026-10-21
狀態：draft（例句等使用者定範圍）
版本：（發行後填）

## 目的
第一位客戶用的是 Windows 上的 Claude Code 桌面版。現在 plugin 只在開發機用 `--plugin-dir` 跑過：桌面版怎麼裝、有新版怎麼讓客戶知道、怎麼升、升完狀態檔怎麼遷移、裝不起來或 hook 沒跑時怎麼發現，都還沒有做。B-008 spike 已經驗出 D-072 的前提有兩條不成立（桌面版不收本機路徑 marketplace；升級要在畫面上點五步、更新完不提示重開）。這題把「從一台全新的客戶電腦到每次升級」這條路做出來，並在桌面版把全部 hook 驗一次（D-133 2026-10-21 補）。

## 決策
（談的時候填）相關的既有決策：D-072（安裝與升級，要重談）、D-054（升級不重做卡）、D-009（build 指令不代叫）、D-019（不寫 plugin 路徑進狀態檔）、D-060（開場版本行）、D-070（常駐預算）、D-023（客戶電腦沒有 git）。相關 backlog：B-014、B-016、B-060、B-041。
