# 桌面版安裝與發行

## 目的
第一位客戶用的是 Windows 上的 Claude Code 桌面版，但 plugin 到現在只在開發機用 `--plugin-dir` 跑過，每一題的確認也都在 CLI 做。B-008 spike 驗出 D-072 的前提有兩條不成立：桌面版不收本機路徑的 marketplace；升級要在畫面上點五步，更新完也不提示重開。這題讓 plugin 裝得進客戶的桌面版：決定發行管道、在桌面版把全部 hook 驗一次、寫好服務人員的安裝步驟。之後各題的確認就能在桌面版做。升級與遷移在「備份、還原、升級與換電腦」那題；環境檢查在 build（D-133 2026-10-21 的兩段補）。

## 決策
（談的時候填）相關的既有決策：D-072（安裝那一半要重談）、D-019（不寫 plugin 路徑進狀態檔）、D-023（客戶電腦沒有 git）、D-070（常駐預算）。相關 backlog：B-060、B-041。
