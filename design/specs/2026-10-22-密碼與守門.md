# 密碼與守門
日期：2026-10-22
狀態：draft（範圍已定，談做法中）
版本：（發行後填）

## 目的
檔名像密碼或金鑰的檔，守門一律不讀，加密的檔讀不到，這是預設（D-079、D-081、D-050）。但客戶會說「那份網站密碼檔可以讀」「這份 PDF 的密碼是 …」，現在都只能回「這版做不到」（note 的 references 第三節）。另外守門在之前幾題的確認裡誤擋過正常的指令（B-024、B-022、B-088、B-049），遮密碼的程式遮太多也漏遮（B-047、B-087），守門掛掉時 Claude Code 照常放行（B-016）。這題把這些一起做，做 security-review（D-145、D-133 2026-10-21 補）；桌面版安裝 spike（B-093）查出的守門問題也收在這裡。

## 決策
D-179（一題做完不拆；登入與 API 金鑰之後補）、D-180（對話裡給的密碼存憑證管理員）、D-181（同一種：密碼檔問一句、加密檔授權後 AI 認出直接開）。D-182（這版只解加密的 PDF）。D-183（「可以讀」的密碼檔卡上不抄密碼、問時讀原檔；裁示拿掉「可以記」）。D-184（「可以讀」跟著那份檔走，內容改了照樣可以讀，不讀最優先）。D-185（夾裡有密碼檔時只列檔名放行，收 B-049）。D-186（照 shell 語法拆指令，收 B-024；B-022、B-088、B-016 一起修）。D-187（遮值只遮值本身，程式加 AI 兩層，收 B-047、B-087）。相關的既有決策：D-145、D-050、D-079、D-081、D-041、D-149、D-150、D-073、D-046、I-111、I-106。
