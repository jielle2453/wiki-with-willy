# 知識庫

這個資料夾是 wiki-with-willy 維護的知識庫。客戶的原始檔案可能在外面登記的資料夾，也可能在這裡；動它們照核心規則 R-04，先留一份再做。她開著的 Word、Excel、PowerPoint 要改（她說開著，或看到 ~$ 鎖檔），用 PowerShell 的 GetActiveObject 附著到開著的那份、用完整路徑（FullName）比對、直接改，文件原本沒有沒存的編輯（Saved 是 True）才替她存檔，有的話照改、不替她存、回報時請她自己存，不拿副本、不開修訂、不關她的檔也不關 Office；退回請她在 Office 按復原。做 Office、PDF 檔：原檔先 kb office copy "<原檔>" --unpack 拿副本，新的在工作區做；做好一律 kb output save 放進來（蓋回原檔留同夾版本檔，最後問要不要刪），匯出、另存也是，不直接寫進知識庫或原檔。客戶講繁體中文，回答客戶一律繁體中文。工具之間的過場也是給客戶看的，一律繁體中文、不唸步驟編號。

第一層有四區：
- 型別夾：名字是客戶自己的分類，前面有編號（例如 01 案子、02 客戶、03 廠商），一個實體一夾，夾裡跟夾同名的 .md 是綜合卡；客戶改了名字就照他的。
- 暫存區：還不知道歸到哪的東西——AI 猜不到放哪的檔、不屬於任何案子的成品和草稿；willy 不會自動清，相關的時候問要放哪。
- 檔案索引：每份原檔一張檔案卡，位置由程式排。
- 系統：程式產生的報表與紀錄，客戶可以開。

對話開頭應該有一段「【wiki-with-willy】」開頭的開場段（子代理沒有開場段，這段不適用）。沒有就是程式沒跑起來：告訴客戶，自己查（python --version、where python、py --version），缺的話自己裝（winget install Python.Python.3.12，跳出系統管理員視窗請客戶按「是」），裝完請客戶關掉 Claude Code 重開。Python 正常就看外掛有沒有裝著、啟用（claude plugin list），沒啟用就幫他啟用。在那之前只有改檔先停；試過還是不行才請服務人員。
