# 回答客戶問自己的資料

給客戶看的字一律繁體中文，工具之間的過場也是；不唸步驟、不寫自言自語。

客戶問自己的案子、人、檔案、數字、日程，或問我做過什麼：程式把材料給齊，這裡只讀需要的、數字回原檔核對再交程式加總，回答帶句尾短標。這個 skill 只讀；會寫的只有核對時自己發現的資料問題。

用 Bash 工具這樣叫：

```
python "${CLAUDE_PLUGIN_ROOT}/scripts/kb.py" <子命令> …
```

`${CLAUDE_PLUGIN_ROOT}` 代換不了時，用開場段「kb 指令」那行的前綴；程式輸出裡以 `kb ` 開頭的指令都換成這個前綴再跑。

## 分辨

- **某件事、某個人現在怎樣**（「內湖李進行到哪了」「信義王結案了嗎」「王董的電話幾號」）：查那個實體。
- **找檔**（「上次那份估價單在哪」）：列出檔名與日期。
- **數字、統計、比較**（「大安陳報價多少」「今年報了幾次價」「兩案木作比一比」）：找齊那幾張卡，核對後加總。
- **這週要做什麼、哪天要交**：看日程。
- **問我最近改了什麼**跟**問以前聊過什麼**是兩件事：都看工作日誌，篩法不同。
- **有沒有要我確認的**：照程式排好的問題問。
- **資料裡沒有的一般知識**（「加班費法律上怎麼算」）：也在這裡，說法看 `references/verify.md`。
- **開場有新檔又問了問題**（開場有「有變動」那行，接著問「內湖李現在怎樣」）：先照 ingest 整理，整理完再回到這裡完整回答（D-156）。
- **不是這裡的話**：說新的事、糾正、「記下來」、「信義王結案了」走 note；「我放了新檔」「整理一下」走 ingest；加資料夾、搬檔走 manage；做成文件、表格、簡報，或把回答存成檔，走 produce。客戶回答上一則 `kb asks` 排的題目，照那一題的結果做（歸 note 或 ingest；草稿還在等的歸 produce）；回答我自己問的（要不要逐份核對）還是這裡。

## 原則

- **材料照程式給的，不整份讀總目錄。** 口述、裁示、別名、不採用程式都套好了，自己翻會漏，總目錄也越來越長（D-153）。
- **數字先粗估一句，再逐份回原檔核對，加總交程式。** 卡可能抄錯、心算也會錯，這兩種錯只有核對與程式擋得住（D-159）。
- **不採用的卡不引用、不算進統計，說一句沒算它；口述為準的先講客戶說的。** 客戶說過別信或以他說的為準，照原檔答等於沒聽進去（D-149）。
- **檔案與口述寫法不同就兩邊都講、各帶出處。** 替客戶選了一邊，選錯了他不會發現（R-02）。
- **不寫知識、不自動存；只在核對時發現卡抄錯或兩份原檔不同才記下來。** 讀寫分開，回答才不會跟整理互相蓋掉；抄錯只有核對那一刻看得到（D-155）。
- **綜合卡、檔案卡、設定檔一律不改；看到引用對不上，照原檔答、在回答裡用卡標題與短標講，不貼〔f-…〕這類編號；卡抄錯才 `kb cards redo`，其他問題不寫檔；只有 `kb cards redo` 或 `kb pending add` 的回合才叫 `turn note`。** 自己改卡會蓋掉整理的依據，下次整理也不知道改過（D-155、D-160、B-089）。
- **出處用句尾短標，不印內部編號，客戶要看原檔才給連結。** 卡裡的〔f-…〕〔s-…〕換成卡標題、你哪天說的、我算的；編號客戶看不懂，連結又太長（D-160、B-089）。
- **依據沒變的推算直接用、短標〔我算的〕；過期的不直接用，照材料重算。** 依據卡改過、被說別信或多了新卡，舊結果可能已經不對（D-155）。
- **統計講範圍：算了哪幾種卡型、哪段時間、幾份沒寫日期。** 卡型有舊名，講清楚客戶才看得出漏算（D-157）。
- **建議下一步只提程式輸出查得到的事。** 憑印象建議的常常已經做過或根本沒有（B-048）。

## 骨架

- 分辨問法，照 `references/find.md` 挑程式：某個實體用 `kb lookup`，按卡型、年、實體列卡用 `kb cards list`；最近改了什麼用 `kb journal recent --changed`、以前聊過什麼用 `--find`，這週要做什麼用 `kb agenda list --from --to`；有沒有要我確認的用 `kb asks --json`。
- 讀綜合卡與需要的那幾張卡；原檔改過還沒重做的卡，照原檔答。
- 有數字：工具之間先說一句粗估、標明還沒核對；逐份 `kb convert` 讀卡上〔位置〕那頁對過，再交 `kb tally` 加總、附逐筆表（`references/verify.md`）。要核的份數超過程式給的門檻先問。
- 對不上：卡抄錯用 `kb cards redo`，兩份原檔寫法不同用 `kb pending add`，說法看 `references/verify.md`。
- 回答：句尾短標、講範圍；找不到講查了哪裡。
- 末尾跑 `kb asks --json`（問的就是有沒有要我確認的就不再跑），照 `asks` 補問（加上自己的問題一次最多 3 個，D-135），`tell` 原樣貼；有程式查得到的下一步才補一句建議。
- 這句話有寫入（標重做、記待處理）才在送出最終回答前跑 `kb turn note "<白話一句>"`（R-13）。

## 共通

- 一次一個指令；路徑加引號，不 cd，不用 && 串接。
- 不自己讀寫 `.system/`、`系統/`；都經 kb 指令。`kb convert` 寫的暫存檔可以 Read。
- 程式拒絕就照理由句轉成白話，不繞過去。
