# 製卡規則（寫給製卡者）

一張檔案卡讓之後的人不用打開原檔就知道「這是什麼、重點在哪、要查細節去哪一頁」。卡是索引不是副本：抄多少由你判斷，數值要用時回原檔讀（D-032）。範本在 plugin 的 `templates/card.md`，只看段落樣式；它第一行的註解不抄（卡的第一行一定是 `---`），檔頭照 todo 的 `header`。

## 一、讀原檔

- 先跑 `convert <編號>`，照它印的做：
  - 「暫存檔：…」→ 用 Read 讀那個暫存檔；長的分段讀（每次 offset、limit 一段），讀完不用刪。
  - 「PDF：N 頁；用 Read 讀原檔：…」→ Read 原檔帶 `pages`，一次最多 20 頁。印了「超過 N 頁」就只讀前 N 頁，`讀取` 填「部分」，「沒讀到的部分」段寫哪幾頁沒讀。
  - 「圖片：用 Read 看：…」→ Read 看圖，照看到的寫。圖片型 PDF（Read 讀出來沒有文字只有頁面圖）一樣照看到的寫，不要寫成空卡。
  - 「讀不到：…」→ 這份不做卡；程式已記進待處理，回答末尾講原因。
- xlsx 的暫存檔每行開頭是「第 N 列：」，N 是工作表裡的真實列號，〔位置〕照抄這個 N。暫存檔最後一行是「（只抽到工作表「X」第 N 列）」時，後面沒抽到：`讀取` 填「部分」，「沒讀到的部分」寫從哪個工作表哪一列以後沒抽。
- 「大檔：照 carding.md 摘要加定位」→ 不逐段抄，寫整份的結構與每部分在哪（第幾頁、哪個工作表、第幾列到第幾列），卡仍守第四節的長度。
- 「轉換結果是空的」→ 見第六節。

## 二、檔頭

檔頭是卡的第一段，`---` 包起來。機器欄位照 `cards todo --json` 給的 `header` 一字不改照抄（含 `開原檔` 那行、`內容指紋` 那行有就留著），只填寫著（填）的欄，加上 `敏感資料種類`（原檔有個資就把 `[]` 換成種類）。鍵名、順序固定：

| 鍵 | 誰填 | 值 |
|---|---|---|
| `編號` | 照抄 | 清冊編號，f- 開頭 |
| `出處` | 照抄 | 客戶原檔、對話收件、AI 產出 三者之一 |
| `原檔` | 照抄 | 清單，每行 `  - file://別名/相對路徑`，同一份內容在幾處就幾行 |
| `指紋` | 照抄 | 64 碼 |
| `內容指紋` | 照抄 | 64 碼；只有 docx、xlsx、pptx 有，header 沒這行就不寫 |
| `標題` | 你填 | 40 字內，講這份是什麼（「信義王報價第三版」），不抄原檔名、不加副檔名 |
| `卡型` | 你填 | 一個名詞：報價、合約、會議紀錄、型錄、進度表、範本、說明、其他 |
| `文件日期` | 你填 | YYYY-MM-DD；文件上寫民國就換西元（115 年 10 月 1 日 → 2026-10-01）；找不到寫「未載」 |
| `讀取` | 你填 | 完整 或 部分（只讀了一部分頁、工作表抽到一半都算部分） |
| `製卡日期` | 照抄 | 今天 |
| `範本版本` | 照抄 | 1 |
| `敏感資料種類` | 你填 | 清單，只記種類不記值：`[身分證, 銀行帳號]`；沒有就 `[]` |
| `開原檔` | 照抄 | `file:///` 開頭的連結，客戶點它開原檔 |

檔名：`filename_pattern` 的 `<標題>` 換成你填的標題原字，放在 `dir`（路徑是總資料夾接 `dir`）。所以標題本身就不要用 `\ / : * ? " < > |`、不以點或空白結尾、40 字內，寫之前先對一次：檔名寫錯被打回時，錯名的檔已經寫進 `檔案索引/`，你刪不掉，只能回答末尾告訴客戶。檔頭其他欄寫錯被打回，照原因改好、同一個路徑整張重寫。

## 三、正文

檔頭之後空一行，寫 `# <標題>`，接著：

1. 第一段一到兩句：這是什麼文件、給誰、做什麼用。AI 產出的卡（出處「AI 產出」）第一段寫明「AI 於 YYYY-MM-DD 起草」，日期用 todo 那一項的 `created`（是 null 就用製卡日期）。
2. 預設段落，沒內容的段整段不寫：
   - `## 重點`：這份檔要記住的事，一點一行。
   - `## 日期與數字`：期限、金額、數量、面積；照原檔寫，不換算。
   - `## 提到的人與單位`：人名加角色、公司、廠商。
   - `## 沒讀到的部分`：讀取是「部分」時寫哪些沒讀、為什麼。
3. 每一點結尾一個〔位置〕，讓人回原檔找得到：
   - PDF：〔第 3 頁〕
   - xlsx：〔工作表「總表」第 12 列〕
   - pptx：〔投影片 4〕
   - docx、純文字：〔「二、付款方式」段〕或〔第 5 段〕
   - 圖片：〔圖左上〕這類看得懂的描述

## 四、長度與忠實

- 正文 300～800 字。大檔摘要加定位，不超過 800 字。
- 只寫原檔有的。換算、加總、推論要註明是你算的（「三期合計 1,280,000 元（依第 2 頁三筆相加）」）。
- 同一件事原檔前後寫法不同（兩個金額、兩個日期），兩個都記、各帶〔位置〕，不替客戶選。
- 重做（stale）：原檔改過，先 Read `existing_card` 拿舊標題，標題不改，整張寫回 `existing_card` 那個路徑，不在舊卡上補。換標題會變成兩張同編號的卡，舊的刪不掉。

## 五、個資不抄

- 不抄進卡：身分證字號、護照號碼、銀行帳號、信用卡號、密碼、個人薪資金額。只在 `敏感資料種類` 記種類。
- 統一編號、電話、地址預設也只記種類（`[統編, 電話]`），正文寫「有廠商統編與電話〔工作表「聯絡」〕」，不寫號碼。
- 人名、公司名、案名可以寫。

## 六、特殊情況

- 轉換結果是空的（空檔）：照樣寫一張，正文只有第一段「這份檔案沒有文字內容」，`讀取` 填「完整」。
- 檔名像密碼或金鑰、只在雲端、太大的檔：todo 不會列，不做卡；回答末尾講一句。只在雲端的請客戶「在檔案上按右鍵選保留在這台電腦上」，之後再整理。
- 讀不到（有密碼、舊格式、不支援、檔案壞了）：不做卡，回答末尾講原因；舊格式請客戶用 Word／Excel 另存成新格式。
- 圖片型或掃描型 PDF：Read 看頁面圖照看到的寫；看不清的段寫進「沒讀到的部分」。
- 同一份內容在多處：只做一張卡（todo 只列一次），`原檔` 清單會列出全部位置。
