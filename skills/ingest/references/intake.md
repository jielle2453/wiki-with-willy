# kb intake：收進知識庫

對話裡給的檔用 `kb intake` 收，不手寫進去。收進來的檔照常整理成卡，出處是「對話收件」，卡上多一行 `收件`。

## 一、三種用法

| 情況 | 指令 |
|---|---|
| 拖檔進對話（拿到的是檔的路徑） | `intake "<路徑>" [--to "<夾>"]`；原檔名看不出內容加 `--title "<名字>"`（副檔名程式照原檔加） |
| 桌面版把圖片檔拖進對話（拿到的是圖，沒有路徑） | 等於貼圖：照下一列存，照內容取名、說一聲；不說「原本叫…」（不知道原檔名，D-240 補） |
| 這一句貼了圖或一段文字 | 先 `intake --pasted list`，再 `intake --pasted image:<n> --title "<名字>"` 或 `intake --pasted text:<n> --title "<名字>"` |
| 程式、skill 交來的 | `intake "<路徑>" --from "<來源名>"`；定期同步同一份加 `--name "<項目名>"` |

- **放哪你判斷**（看檔名、內容、客戶剛在談的案子）：看得出屬於哪個案子或夾就帶 `--to "<夾>"`，收好說一聲放哪；猜不到才不帶，落暫存區。貼的圖和文字同樣可以帶 `--to`。

- 好幾份一起拖：一次給好幾個路徑，各自一行結果；`--title`、`--name` 一次只收一份。
- 名字（`--title`、`--from`、`--name`）不能有 `\ / : * ? " < > | $` 與反引號，不以點或 `~$` 開頭；貼的東西沒有檔名，`--title` 寫「<日期> <照內容取的名字>」（`2026-10-26 陳經理名片`）。
- 原檔名看得出內容就照用，不給 `--title`；`IMG_2034.jpg`、`下載 (3).pdf`、`scan001.pdf` 這種才自己取，收完說一聲取了什麼名字（D-245）。

## 二、--pasted 從哪裡拿

程式從這一句的對話紀錄取客戶最後那則訊息，與緊接在它前面的上一則：圖照原格式存（png、jpg、webp，不轉檔），系統另存了原圖就用原圖；文字取桌面版 `<pasted_content>` 包起來的每一段，沒有這個標記（VS Code、終端機）就取那則訊息的全文。

- `list` 分兩段：「這一則：」底下是這一則的（`image:1（image/png，12345 位元組）`、`text:1（230 字）`），「上一則：」底下是上一則的，前面多 `prev:`（`prev:text:1（230 字）`）；沒有的那段不印。印「這一句沒有貼圖或文字」就是兩則都沒有。
- 上一則用在：她貼了一段像文件的文字、你問要不要存、她這一則回「存起來」——要存的在上一則，跑 `intake --pasted prev:text:<n> --title "<名字>"`（圖是 `prev:image:<n>`）。
- 再往前的拿不到；請她再貼一次。在終端機跑、或這一句已經答完才跑的，一律拿不到。
- 拿不到時程式回那一句，照講；不要自己把內容重打一遍存成檔（保證不了一字不差，D-048）。
- 從紀錄取的圖可能被縮過，卡上會標「對話裡的版本」；要列印或存證時先在下載、桌面、圖片夾找同名或同時間的原檔，找到就 `intake` 那份；找不到才請她把原圖拖進對話，一步一步講（桌面版拖圖片進對話也只給得到這一版，裁定 8）。

## 三、輸出

人讀一份一行，接在最後的「接著整理：kb cards dispatch --json」是有新收或更新、又在對話裡跑的才有；照 ingest 骨架從「拿計畫」往下整理。

| 那一行 | 意思 | 結果（`--json` 的 `result`） |
|---|---|---|
| `收進暫存區了：暫存區/合約.pdf（原檔沒動）` | 拖檔收好了 | `new` |
| `收進「王先生」了：王先生/合約.pdf（原檔沒動）` | 帶 `--to` 收好了 | `new` |
| `收進暫存區了：暫存區/王先生合約.jpg（原本叫 IMG_2034.jpg）` | 帶 `--title` 收好了 | `new` |
| `收進暫存區了：暫存區/…` | 貼的、定期交來的第一份 | `new` |
| `更新了：暫存區/公司系統/客戶王先生.md` | 定期交來的內容變了，舊的備進回合，卡下次整理重做 | `updated` |
| `原本放的位置沒有這份了，寫回去了：…` | 定期交來的那份被客戶刪過，照原位置放回（`restored_place`） | `new` |
| `沒有變：…` | 定期交來的內容一樣，沒動 | `same` |
| `這份已經在暫存區：…` | 本來就在暫存區 | `already_inbox` |
| `這份我已經在讀了：客戶案件/大安陳/會議紀錄.docx` | 在登記的資料夾裡，不複製 | `reading` |
| `這份收過了：…` | 同一份內容已經在知識庫，不複製 | `have` |

`--json`：`{"items":[{"path","id","result","said"}],"next"}`；`said` 就是人讀那一行，`next` 是要接著跑的指令或 null。被拒的那份 `result` 是 `refused`，同名的是 `conflict`（帶 `conflict` 列）。

`restored_place`：定期交來的那份客戶刪過、照原位置放回時有，講一句「那份你刪過，我照原位置放回來了」。

## 四、拒絕句與怎麼接著做（exit 3，不用照念，換成怎麼做）

| 句子 | 怎麼辦 |
|---|---|
| `找不到這個檔：<路徑>` | 路徑打錯或檔已搬走；請她再拖一次 |
| `這份已經在知識庫裡：<相對路徑>` | 不用收；要歸位走 manage 的 `source-edit move` |
| `這個位置你說過不讀` | 那個夾客戶設成不讀，不收；他要讀再走 manage 取消不讀 |
| `這個檔名像密碼或金鑰，不收` | 跟客戶說一句原因；不換名字硬收 |
| 「檔名不能有 \ / : * ? " < > \| $ 與反引號這些字元」那句 | 換一個名字再跑 |
| `這張圖拿不到原檔：先在…找…` | 先在下載、桌面、圖片夾找同名或同時間的原檔，找到就 `intake` 那份；找不到才請客戶把原圖拖進對話，一步一步講 |
| `這段拿不到原文：先在…找…` | 同上；找不到才請客戶把內容存成檔再拖進來 |
| `找不到上一則；請把要存的再貼一次` | `prev:` 但這一則前面沒有客戶訊息（剛摺疊、對話第一句）；請她再貼一次 |
| `「X」已經有「Y」（內容一樣／不一樣）` | 同名（`conflict`）：內容一樣不用收；不一樣照下面「同名判斷」選 `--replace`、`--title`／`--name` 換名 |
| `檔名太長，換短一點的名字` | 名字（`--title`，程式交來的看 `--from`、`--name`）取短一點再跑；原檔名本身太長就給 `--title` |
| `--name 要配 --from`、`--pasted 要給 --title`、`--title、--name 一次只收一份` | 參數補齊再跑 |

多份一起收時，被拒的那份一行「<原檔名>：<拒絕句>」、其他照收，整體 exit 3。

**同名判斷**（D-309）：檔名或內容的日期、期間不同（每月同名報表）預設是另一份：另存、檔名帶期間（`--title "月報 11月"`）；同一期間改過才算新版，加 `--replace` 覆蓋（舊的程式先留一份），說一聲。

## 五、收完之後

- 收進暫存區最上層的，整理成卡、卡掛了實體，回答末尾 `asks` 可能有一題「<卡標題>（暫存區）要放到哪裡？」，結果是那個實體的檔放最多的夾（沒資料夾的客戶是實體夾）與「先放著」；她選了就照那個結果的 `do` 搬（D-244）。willy 不會自動清暫存區，相關的時候問要放哪。
- 問放哪時照那題的結果列選項，不自己另想去處；第一個（程式照份數排的，放最多的那個）就是推薦，講成「建議放到 X」（裁定 8）。
- 她收的時候就說了放哪（「存到王先生的夾」）：收的時候直接帶 `--to`，不再問。實體夾還沒建時程式會先建。
- 來源子夾（`暫存區/<來源>/`）裡的是定期交來的，不問放哪；搬走的話下次交來照清冊找到現在的位置更新。

## 六、寫給外部程式與 skill

公司系統的擷取程式、排程、別的 skill 要把東西交進知識庫，在知識庫資料夾裡跑：

```
python "<plugin 路徑>/scripts/kb.py" intake "<檔的路徑>" --from "<來源名>" [--name "<項目名>"] [--json]
```

- 一律帶 `--from`（卡上記「從<來源名>」，回答時說「從 X 取回的」，D-242）。
- 同一份會一直更新的（某位客戶的資料、價目表）帶 `--name`：第一次照上面「放哪你判斷」帶 `--to "<夾>/<檔名>"`，說一聲「之後會更新在這裡」（D-325）；猜不到才不帶，落 `暫存區/<來源名>/<項目名>`。之後同來源同項目不帶 `--to`，覆蓋那份現在的位置、內容一樣不動，舊的備進回合退得回。一次性的不帶 `--name`。
- 只管交檔，不用自己整理：AI 照常整理成卡。
- exit 0 是收好、沒變或已經有了；exit 3 是被拒（第一行是原因）；其他是程式出錯。
