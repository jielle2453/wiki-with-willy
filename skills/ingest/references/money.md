# 錢與數字欄（寫給做卡的）

批次的 `read` 有這份才照做（材料的 `profile.money_mode` 是 `on`，或 `profile.fields` 有欄；子代理與主對話自己做卡都一樣）。每寫完一張卡（日程批次的每張 `agenda_unscanned`）、抽完日期後接著做。帳的寫入只經 `kb money`、數字欄只經 `kb entity field`，`add`、`settle`、`attach` 一律帶 `--card`（沒帶會被擋）；她口述的錢走 note，不是這裡。

## 一、數字欄（不管帳開不開都做）

`profile.fields` 是 `{型別: [{"field","unit"}]}`。卡掛的實體是那個型別、卡上讀得到那一欄的值（型錄的售價、報價單的進價、包裝寫一箱 24 瓶、合約總價）：

```
kb entity field 精華液 售價=1800 進價=1200 --card <這張卡的編號>
```

- 一次可以給好幾欄；數字照文件寫（1,800、3萬都收），不收負數。程式自己判斷新舊、她說過的不蓋掉（回 `kept`）、分不出新舊開待處理（回 `conflicts`），你不用處理。
- 一次性的價格（這張報價給這位客戶的折扣價）不是固定的數字，不設欄。
- 沒有那個型別的欄、或卡上沒有那個數字就不跑。

## 二、錢（只在 `profile.money_mode` 是 `on`）

`money_mode` 不是 `on` 這節整節跳過。

### 判斷流向（D-274）

照 `profile.about`（她是誰：個人或公司）與文件上誰付給誰（發票的買方賣方、收據、合約的甲乙方、出貨單、匯款單）：

| 文件 | 怎麼做 |
|---|---|
| 她收的（她開給客戶的發票、客戶的匯款單、合約裡客戶要付她的款） | `--dir 收` |
| 她付的（廠商開給她的進貨單、發票、工班請款單） | `--dir 付` |
| 不是她的錢（客戶自己的保單保費、別人之間的交易）、還沒成立的（報價、價目表、型錄） | 不記 |
| 看不出是不是她的、誰付誰 | `kb money unsure --card <卡編號> --text '<讀到什麼、哪裡看不出>'`，程式會問她；不猜 |

材料的 `profile.preferences` 裡講整理時錢要怎麼記的照做（例：「員工報帳的收據不用記，進貨單要記」，D-503、D-504）。

### 怎麼記

```
kb money add --card <卡編號> --dir 付 --amount 36000 --date 2026-10-02 --entity 原廠 --item '精華液 +24@1200' --text 進貨
```

- 已經付了、收了（收據、匯款單、發票上寫已付）用 `--date` 那天；還沒（請款單、合約的分期款、到期日）用 `--due` 到期日，金額寫不出來就不給 `--amount`（未知）。
- 沒寫日期（合約沒寫哪天付）就 `--date`、`--due` 都不給：程式記成還沒收付、沒到期日，不要記成今天收了。
- `--text`、`--item` 用單引號包，字有 `$` 這類符號時雙引號會被 shell 吃掉。
- `--entity` 掛登記過的實體（沒登記的照 carding.md 先登記，看不出的就不掛）。
- 品項照文件：`--item "<商品> <±數量>[單位][@單價][在<地點>]"`，進貨是正、出貨是負；單位是箱這類包裝而程式說沒有「每箱」就寫基本單位的數量（文件上看得到的話），看不到就不寫品項。地點只在設定檔第十節有地點型別、文件寫明哪個分店或倉庫時才寫。
- 合約的分期款每期一筆 `--due`；同一件事日程那邊只加交屋這類不涉錢的事，不另加「付第二期款」的日程。
- `--card` 讓程式記出處與指紋、標推測；同一張卡同方向同金額同日再記一次不會重複。

### 可能同一筆（D-276）

`add` 回 exit 3、`refused: candidates`：

- 明顯是同一筆（她講過的那筆，現在讀到收據）：`kb money attach <那筆的編號> --card <卡編號>` 補出處，不另記。
- 是一筆還沒收付的（`open: true`）這次收付了（合約的第二期，讀到匯款單）：`kb money settle <編號> --date <那天> --card <卡編號>`，金額不夠加 `--amount`（程式拆）。
- 明顯是另一筆：原指令加 `--new`。
- 看不出：加 `--new --unsure <那筆的編號>`，程式會問她。

## 三、每張都要

抽完（沒抽到也算）跑 `kb money scanned <卡編號>`，程式才知道這張看過了，不然下次還會列。

回報不用列記了哪些帳；回答末尾由程式的 `tell` 說（「我從檔案記了 3 筆帳：…」）。
