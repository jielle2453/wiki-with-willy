# 整批不對：重做或不整理

客戶說「剛剛那批整理得不對，全部退回」「退到整理之前」「那些卡都不要」時用。這版不一路退回（D-228）：退回只退最近一句，整批的卡散在好幾句裡（說停、再說繼續整理，會開第二次整理），一句一句退會連客戶後來答的事一起退掉。

## 一、先問一句

照這句問，不替她選：

「是卡寫得不對要重做，還是這些檔本來就不想讓我整理？」

- 卡寫錯了、抄錯、讀錯、要重新整理 → 第二節，整批重做。
- 這些檔不該整理、不想讓我看、那夾不要讀 → 第三節，交給 manage。
- 只是最近一句（剛答的名字、剛收的草稿）不對 → 照核心規則 R-05 退回最近一句。

## 二、整批重做

1. 跑 `kb cards status --json`，看 `jobs`：這個對話的每次整理，舊到新，各帶 `cards`（寫好了的卡）。「剛剛那批」是從她說整理的那一句起的每一次（中途說停又說繼續整理的，會有兩三次，要一起標）；在別的對話整理的看 `other_jobs`。
2. 先列：`kb cards redo --job <第一次> --job <第二次> --check`，印 `要標成重做的卡 N 張：` 與每張的卡標題、原檔名（人讀不印編號，`--json` 帶 `cards` 清單）。照列給她看，問「這 N 張都重做嗎？」，她說好才做下一步。
3. 標：同一行拿掉 `--check` 再跑，印 `已標成要重做：N 張卡，下次整理時照原檔重寫`，掛著這些卡的綜合卡多一行 `連帶要更新的綜合卡：…`。標完照 SKILL 骨架「拿計畫」：todo 的 `stale` 收這些卡（`reason` 是「客戶說卡讀錯了」），dispatch 交製卡助手照原檔重寫，綜合卡跟著更新（D-147）。
4. 回答說標了幾張、正在重寫；不對可以說退回（退的是標記那一句）。

拒絕（exit 3），一字不差：

| 程式說 | 你做 |
|---|---|
| `沒有這次整理：j-…` | 編號抄錯或那次整理太舊（留 30 天）；重跑 `cards status --json` 照 `jobs` 給 |
| `這次整理沒有寫好的卡` | 那幾次還沒寫出卡（剛派就停了）；跟她說沒有卡要重做 |
| `給一張卡的編號，或用 --job 給整理的編號，擇一` | 參數給錯，照上面的寫法重跑 |

## 三、不想讓我整理

這些檔本來就不該整理：照 manage 的 `references/sources.md` 跑 `kb folders exclude`（不讀那夾或那份），卡會跟著拿掉。她說的是「不想讓 AI 看到」照那裡的 hidden 做。不用標重做、不用退回。
