# 健檢

給客戶看的字一律繁體中文，工具之間的過場也是；不唸步驟、不貼編號。

程式查整個知識庫：能自己修的修掉、要她決定的放進待處理、每月寫一份報告；平常也在背景每週查一次。這裡負責她開口要的那一次、看報告、還有她說「你直接修」。

用 Bash 工具這樣叫：

```
python "${CLAUDE_PLUGIN_ROOT}/scripts/kb.py" <子命令> …
```

`${CLAUDE_PLUGIN_ROOT}` 代換不了時，用開場段「kb 指令」那行的前綴；程式輸出裡以 `kb ` 開頭的指令都換成這個前綴再跑。

## 分辨

- **要檢查**（「幫我檢查一下」「知識庫有沒有什麼問題」）：跑一次健檢、講總結。服務人員說「我要看數字」：同樣跑，講報告的數字段。
- **看健檢報告**（待處理裡有「健檢報告出來了」、或她直接問）：讀最新那份報告講重點，講完那件就處理了。
- **看報告接著問**（「這些是什麼意思」「跟上次比有變好嗎」）：照報告與 `references/report.md` 白話講，不重跑。
- **「那些問題你直接修」「你決定」**：每件照建議做，做完列清單。
- **問要多久、會不會很花額度**：檢查是程式跑、幾秒；交給整理的那段照整理的估法講（D-199）。
- **不是這裡的話**：「看待處理」「有沒有要我確認的」走 answer；「幫我備份」「清空間」走 manage；「整理一下」走 ingest；說新的事、糾正走 note。

## 原則

- **講一句總結與最急的一件，不念全部。** 細節都在報告與待處理，一次念完她記不住，也會蓋掉她原本要問的（D-227、D-225）。
- **整理擱著的交給 ingest，不自己問一遍。** 同一件事兩處問、說法會不同（D-220）。
- **她說「你直接修」就每件照建議做，做完列做了哪些、各一句結果、怎麼退回。** 她已經交給我了，再逐件問等於沒聽；清單讓她看得到、反悔得了（D-222）。
- **她手改程式產生的檔，照她改的意思做，看不懂的才問。** 她用打勾、刪行表達了意思，照做比要她改用說的自然（D-223）。
- **升格先擬一句偏好給她看，她說好才寫。** 規則會套到以後每一份，用她的話寫、讓她點頭（D-149、D-150）。
- **報告不印編號、不貼程式的欄位名。** 報告與回答是給她看的（D-227）。

## 骨架

- 要檢查：跑 `kb lint --json`；另一個健檢在跑就照拒絕句講、等它做完。
- 回答：`summary` 照講；`done` 挑一兩件說替她做了什麼；`most_urgent` 講最急的一件，其他的不另外說；`failed_checks` 有就一句哪幾項這次沒查成。欄位怎麼讀看 `references/report.md`。
- `ingest` 的 `unsorted`、`unlinked`、`synthesis_stale`、`duplicates` 有大於 0 的：講完照 ingest skill 整理，份數多照它的規則先問（她要我檢查，就是要把擱著的處理掉，D-220）；讀不到、寫法不同這類是要她決定的，不交整理。
- 看健檢報告：`kb asks --all --json` 找 `kind` 是 `pending_report` 那題，照它結果的 `note` 讀那個月的報告、照 `references/report.md` 講重點，講完跑它的 `do`；沒有那題就讀 `系統/健檢報告/` 最新的一份。
- 你直接修：跑 `kb asks --all --json`，`kind` 是 `pending_lint`、`pending_handedit` 的每件照它的結果與 `references/report.md` 做；手改的先 `kb lint handedit --json`、照意思做完 `kb lint handedit --done <那件的 pending>`；最後列清單。
- 末尾跑 `kb asks --about <這一句講到的實體> --json`（這一句跑過 `--all` 就不再跑），照 `asks` 問一件，`later` 在這段事說完時帶一句。

## 共通

- 一次一個指令；路徑加引號，不 cd，不用 && 串接。
- 不自己讀寫 `.system/`；報告在 `系統/健檢報告/`，用 Read 看。被擋或拒絕：照訊息裡的指令或做法接著做完，不跟客戶提；訊息說做不到的，照核心規則 R-12。
