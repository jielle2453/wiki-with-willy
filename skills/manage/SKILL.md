# 管資料夾、原檔位置與整個知識庫

給客戶看的字一律繁體中文，工具之間的過場也是；不唸步驟、不寫自言自語。

客戶要我管「讀哪些資料夾」「原檔放在哪」或「整個知識庫」。這裡只管我做不穩的事：動原檔先留一份、還原先講一句、退回救不救得回、數數交給程式。

用 Bash 工具這樣叫：

```
python "${CLAUDE_PLUGIN_ROOT}/scripts/kb.py" <子命令> …
```

`${CLAUDE_PLUGIN_ROOT}` 代換不了時，用開場段「kb 指令」那行的前綴；程式輸出裡的 `kb ` 指令也換成這個前綴。

## 分辨

- **管讀哪些資料夾**（`kb folders`）：加、不讀（不想讓 AI 看到、用不到）、拿掉、恢復讀、現在讀哪些、登記的夾搬家或改名了。
- **動原檔**（`kb source-edit`）：搬一份或整個夾、改檔名、刪。沒說放哪看 `where` 推薦，看得出就直接搬、說一聲，兩個夾差不多才問一句；說了夾只對到一個就直接搬。
- **整個知識庫**（`kb backup`、`restore`、`versions clean`、`moved`、`output links`、`upgrade`）：備份、回到某份備份、空間不夠、換位置或換電腦、換帳號、升級。「上一步、剛剛」是退回（`kb versions`，R-05），「整個回到某天」是還原，「退回舊版」是換回舊版；分不清問一句。
- **不是這裡**：自己在檔案總管搬了檔 → ingest；實體改名 → note；改檔案內容 → produce；整批整理不對 → ingest（先問重做還是不想讓我整理）；重建知識庫先拍快照再代做（R-07）。
- 「那個不要了」拿不準是不讀還是刪檔，先問；刪整個夾用 `kb source-edit trash` 收夾（B-098）。

## 原則

1. **搬、改名、刪用 `kb source-edit`：會備份、記搬動、讓卡跟上，說「退回」才搬得回。** kb 沒有的做法自己來，刪、蓋之前照 R-04 先留一份（D-010、D-074、D-175）。
2. **檔、目標夾、新名字都確定就直接做、做完複述；有一件不確定才問。** 多問很囉嗦，搬錯靠退回救得回（D-176）。
3. **刪檔與同名取代：先留一份就做，做完說一句可以改回。** 進不了回收筒的程式先留備份；kb 說救不回來才白話問一句（D-173、D-174、I-082）。
4. **「不想讓 AI 看到」同一句話做完：排除 → 照 `rules/synthesis.md` 重寫程式列的綜合卡 → `kb folders purge`；這一句的 `kb turn note` 在 purge 之前記、不寫檔名、卡名。** 拖到下次綜合卡還寫著她不想看的事；清完的回答不提那夾裡的檔名與內容（D-174）。
5. **跨硬碟照搬：先複製、比對一樣才丟原檔。** 中途失敗原檔還在（D-175）。
6. **推薦去處看 `where` 的數字、問一句；沒有實體的問她放哪個主題的夾。** 數幾十張卡分在哪我做不穩（D-178、D-045）。
7. **資料夾搬家：`kb folders locate` 自己找，找到接上、說一聲，找不到才問；對不太上照實講，她決定換不換。** 猜錯會登記到別處（D-177、D-089）。
8. **還原先 `restore check` 白話講會回到哪天、什麼會不見、原本的資料夾不會動，她說好才 `restore apply`。** 還原會蓋掉這段時間記的口述與日程（D-205、R-07）。
9. **備份只包知識庫，原檔要她自己的備份顧；整個知識庫搬位置一步一步帶她搬。** 原檔包進備份會被當成新檔整理，搬不動自己所在的夾（D-203、D-206）。
10. **講退回一律說「MM-DD HH:MM 那句…」，不唸回合代號；版本只唸版號與一句話。** 客戶看不懂代號（B-074、D-205）。
11. **大升級先講要等、完了開新對話；小修不問；退回舊版先 `upgrade --check` 講會不見什麼，說好才 `--downgrade`。** 快照回得去，退回會丟升級後記的（D-215、D-217、D-205）。

## 骨架

- **加資料夾**：`folders add "<路徑>" --check` → 報份數、提醒；有憑證樣式的檔就說「檔名像密碼或金鑰的預設不讀；要讓我讀哪一份跟我說「X 可以讀」」→ 問別名、問「這個夾同事也會用嗎」（會就加 `--shared`）→ `add`；加完問要不要整理成卡，要就照 ingest。
- **不讀某夾**：`folders find "<夾名>" --json` 在登記的資料夾底下找；找到多個就問，都找不到才說本來就沒在讀；問兩種、只認明確的選擇 → 照那一筆 `exclude` 的現成指令跑，不自己拼引號；`exclude` 是 null 的照 `note` 說；hidden 照原則 4。
- **拿掉來源、恢復讀、列出**：`remove`（確認後）、`include`、`list`。**搬家改名了**：`folders locate "<別名>"` 找新位置 → `folders relocate "<別名>" "<新路徑>" --check` → 照實講 → 她說要才去掉 `--check`。
- **搬、改名、刪、放哪**：`source-edit move|rename|trash|where`（`--to` 收 `where` 印的「別名/相對路徑」）；整個夾與刪先 `--check`。
- **整個知識庫**：指令與說法照 `references/ops.md`；備份、清空間先 `--check`，還原先 `restore check`，升級先 `upgrade --check --json`；開場出現「已換到」先 `upgrade --finish`，出現「換了位置」跑 `moved`；換帳號 `output links`。
- **被擋或拒絕**：照訊息裡的指令或做法接著做完，不跟客戶提；訊息說做不到的，照核心規則 R-12。

## 共通

- 回答客戶一律繁體中文；跑之前一句話複述要做什麼，看到程式印的結果才說「已經」。
- 一次一個指令，路徑加引號，不 cd、不用 && 串接；`.system/` 與 `.claude/settings.json` 一律經 kb。
