# 管資料夾與原檔的位置

給客戶看的字一律繁體中文，工具之間的過場也是；不唸步驟、不寫自言自語。

客戶要我管「讀哪些資料夾」或「她的原檔放在哪」。怎麼判斷交給我自己；這裡只管我做不穩的事：原檔一定經 kb 動、刪要明確確認、退回救不救得回、跨硬碟不代搬、數數交給程式。

用 Bash 工具這樣叫：

```
python "${CLAUDE_PLUGIN_ROOT}/scripts/kb.py" <子命令> …
```

`${CLAUDE_PLUGIN_ROOT}` 代換不了時，用開場段「kb 指令」那行的前綴；要跑程式輸出裡寫的 `kb ` 指令時也換成這個前綴。

## 分辨

- **管讀哪些資料夾**（`kb folders`）：加資料夾、不讀某夾（不想讓 AI 看到、用不到兩種）、拿掉來源、恢復讀、現在讀哪些、登記的夾本身搬家或改名了（「報價夾我搬到 E 槽了」；開場「這台電腦找不到來源」也是）。
- **動原檔**（`kb source-edit`）：搬一份（「這份估價單搬到 2026」）、搬整個夾（「信義王整個夾搬到 2025 封存」）、改檔名、刪（「舊備忘幫我刪掉」）。
- **放哪裡**：沒說放哪（「這份要放哪？你決定」）就看 `where` 的數字推薦、問一句；說了夾（「定稿放到王宅那夾」「收件匣那張照片放到信義王那夾」）只對到一個就直接搬，對到兩個以上才用 `where` 列出來問。
- **不是這裡**：她自己在檔案總管搬了檔 → ingest（卡會跟著走）；實體改名（「信義王改叫王宅」）→ note；改檔案內容 → produce；「剛剛那批整理得不對、全部退回」→ ingest（先問重做還是本來就不想讓我整理，後者才回這裡設成不讀）；重建、換電腦、整個知識庫搬位置 → 之後的指令，照實說還不能。
- 「那個不要了」拿不準是以後不讀、還是要刪檔，先問一句。刪整個夾這版不做：請她在檔案總管刪，之後整理時跟上（B-098）。

## 原則

1. **原檔只經 kb 動：搬、改名、刪一律 `kb source-edit`，不用指令或檔案工具自己做。** 守門只放 kb；kb 會備份、記下搬動、讓卡跟上，說「退回」才搬得回去（D-010、D-074、D-175）。
2. **她說的那份檔、目標夾、新名字都確定就直接做，做完複述並說不對可以退回；有一件不確定才問。** 講清楚了還每次問很囉嗦，搬錯靠退回救得回；對到兩份檔、兩個夾、沒說放哪才問（D-176）。
3. **刪檔與同名取代先跑 `source-edit trash "<那份檔>" --check` 講後果，只認明確的確認；退回救不回的（丟進回收筒的、清掉的）都先講。** 退回只搬得回 kb 搬過的，刪的要從資源回收筒拿、清掉的就沒了；要她知道刪哪份、卡會拿掉、哪些綜合卡要更新、OneDrive 會一起刪；「好」「嗯」不算，再問一次（D-173、D-174、I-082）。
4. **「不想讓 AI 看到」同一句話做完：排除 → 照 `rules/synthesis.md`（`cards todo --json` 的 `read` 給路徑）重寫程式列的綜合卡 → `kb folders purge`；程式說已經清好就不用再跑；這一句的 `kb turn note` 在 purge 之前記，不寫檔名、卡名。** 拖到下次，那段時間綜合卡還寫著她不想讓 AI 看的事（D-174）。清完的回答不提那夾裡的檔名與內容。
5. **程式說不同顆硬碟就不代搬：照它給的 `open` 打開兩個夾，請她自己拖。** 跨硬碟要逐份複製，大的夾斷在中途兩邊各一半；檔案總管有進度、同名會問（D-175）。
6. **推薦去處看 `where` 的數字判斷，推薦只是預設答案，問一句。** 數幾十張卡分在哪是我做不穩的事；放哪由她決定（D-178）。沒有實體的就問她放在哪個主題的夾、叫什麼（D-045）。
7. **資料夾搬家對不太上就照實講，她決定換不換。** 搬的時候整理過很正常，不設門檻；幾乎全對不上就問是不是貼錯夾（D-177）。
8. **加資料夾、資料夾搬家的路徑請她從檔案總管位址列貼，不猜。** 猜錯就登記到別的地方（D-089）。

## 骨架

- **加資料夾**：`folders add "<路徑>" --check` → 報份數、提醒；有憑證樣式的檔就說「檔名像密碼或金鑰的預設不讀；要讓我讀哪一份跟我說「X 可以讀」」→ 問別名 → `add`；加完問要不要整理成卡，要就照 ingest。
- **不讀某夾**：`folders find "<夾名>" --json` 在登記的資料夾底下找（不用 Glob，會被守門擋）；找到多個就問是哪一個，都找不到才說本來就沒在讀、請她貼路徑。問兩種、只認明確的選擇 → 照那一筆 `exclude` 給的現成指令跑（`hidden` 或 `unused`），不自己拼引號；`exclude` 是 null 的照 `note` 說；hidden 照輸出做原則 4。
- **拿掉來源、恢復讀、列出**：`remove`（明確確認後）、`include`、`list`。
- **搬家改名了**：`folders relocate "<別名>" "<新路徑>" --check` → 照實講 → 她說要才去掉 `--check` 再跑。
- **搬、改名**：`source-edit move "<檔或夾>" --to "<夾>"`（`--to` 直接收 `where` 印的「別名/相對路徑」）、`source-edit rename "<檔>" "<新名字>"`；整個夾先 `--check`，要不要先問我自己判斷。
- **刪**：`source-edit trash "<檔>" --check` → 講 → 明確說刪 → `trash`。
- **放哪**：`source-edit where --entity "<名稱>"` → 推薦、問 → 說好就 `move`。
- **程式拒絕（exit 3）**：照參考拒絕表那一列做（有的要接著問，或接著跑 `open`、`add`、`relocate`）；不改用別的指令或工具自己做。
- 這句話有寫入，送出最終回答前跑 `kb turn note "<白話一句>"`（R-13）。

## 共通

- 回答客戶一律繁體中文；跑之前一句話複述要做什麼，看到程式印的結果才說「已經」。
- 一次一個指令；路徑加引號，不 cd，不用 && 串接。
- 不自己讀寫 `.system/` 與 `.claude/settings.json`，一律經 kb。
