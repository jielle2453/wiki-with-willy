# 管理讀哪些資料夾

這個 skill 管「知識庫讀哪些資料夾」：加進來、不讀某夾、拿掉來源、取消不讀、列出現況；不碰檔案內容。程式是 `kb folders`，參數、輸出與拒絕原因看 `references/sources.md`。

用 Bash 工具這樣叫：

```
python "${CLAUDE_PLUGIN_ROOT}/scripts/kb.py" folders <子子命令> …
```

`${CLAUDE_PLUGIN_ROOT}` 代換不了（指令說找不到 kb.py，或路徑開頭變成 `/scripts`）時，用開場段「kb 指令」那行的前綴。

## 分辨

- 「幫我搬」「幫我刪」「幫我改名」是要動檔案，這版做不到，照下表「要我搬檔、改名、重建」那列回。
- 「搬到…了」「改名了」「不要了」「不要讀」「還是讀好了」是登記的事，照下表做。
- 拿不準就問：「是要我以後不讀這個資料夾（檔案不動），還是要刪掉裡面的檔案？」

## 做法

| 客戶說 | 做法 |
|---|---|
| 加資料夾（「把…加進來」） | 沒有完整路徑就請客戶從檔案總管的位址列複製貼過來，不猜、不自己找。有路徑先跑 `add "<路徑>" --check`，照 `references/sources.md`「`--check` 報告怎麼轉白話」那節報給客戶；有憑證樣式的檔就說「檔名像密碼或金鑰的預設不讀，這版還不能開放，之後會有」。再問別名可不可以。客戶說好才跑 `add "<路徑>"`（換別名加 `--alias "<別名>"`）。加完說「從現在起讀得到；整理成卡的功能之後補。」 |
| 不讀某夾（「不要讀…」） | 先問：「①不想讓 AI 看到（之前讀過的已送過雲端）②只是用不到，選哪一種？」只認明確的選擇（「1」「不想讓 AI 看到」「用不到」）；回「好」「嗯」就再問一次，這句話裡不做。選①跑 `exclude "<路徑>" --kind hidden`，選②跑 `--kind unused`；客戶講了原因加 `--reason "<一句>"`。轉述程式印的那句。 |
| 拿掉來源（「…不要了」） | 先分清是以後不讀，還是要刪檔；要刪檔請客戶自己在檔案總管刪。以後不讀就再問一次：「確定拿掉「<別名>」？檔案不會動。」只認明確的確認（「對，拿掉」「確定」）；「好」「嗯」不算，再問一次。確認了跑 `remove "<別名>"`，說檔案沒動、說「退回上一版」救得回。 |
| 取消排除（「…還是讀好了」） | 複述一句（原本是「不想讓 AI 看到」的要講出來）就跑 `include "<路徑>"`，轉述程式印的那句。 |
| 現在讀哪些（「讀哪些資料夾」） | 跑 `list`，轉成白話：每個來源講別名、路徑、不讀的夾與原因（`hidden` 說「不想讓 AI 看到」、`unused` 說「用不到」）；標「這台電腦找不到」的一定講出來。 |
| 已經搬好或改好名了（「…搬到 E 槽了」「…改名了」） | 說做法是拿掉舊的、加新的，問要不要現在做；新路徑請客戶貼，不猜。客戶要做：①先跑 `add "<新路徑>" --check --alias "<舊別名>-新位置"`（舊的還登記著，同名會被擋），照「加資料夾」那列報給客戶；被拒就什麼都不動，把原因告訴客戶；②過了跑 `list --json`，記下舊來源的排除（`spec`、`kind`、`reason`）；③照「拿掉來源」那列確認後 `remove`；④`add "<新路徑>"`，別名預設照舊（`--alias "<舊別名>"`），客戶要換就換；⑤舊排除一條一條 `exclude`，路徑是新來源的 `path` 接舊的 `spec`，`--kind`、`--reason` 照舊；⑥跟客戶說補回了哪幾條不讀；被拒絕（夾在新位置找不到）的逐條講出來，`hidden` 的請客戶貼新路徑再排除。 |
| 要我搬檔、改名、重建 | 這版做不到，不用任何指令代做。說怎麼自己做：「搬檔、改名請在檔案總管做；資料夾搬家或改名做完跟我說，我把舊的拿掉、新的加進來。」重建說要等建置功能。 |
| 程式拒絕（exit 3） | 轉述第一行的原因（怎麼說看 `references/sources.md`「常見拒絕」），停下來，不自己換方法、不繞路。那張表寫了下一步的，先問客戶，客戶說好才做。 |

路徑（只用在 `exclude`、`include`）：客戶只講夾名時跑 `list --json`。`include` 用那條排除的 `path`；`exclude` 用來源的 `path` 接上夾名，接不出來或有兩個可能就請客戶貼完整路徑。`add` 的路徑一律請客戶貼。

## 共通

- 跑指令前用一句話複述要做什麼；看到程式印的結果之後才說「已經」。
- 一次一個指令；路徑加引號，不 cd，不用 && 串接。
- 這句話裡改了登記（`add`、`exclude`、`remove`、`include`），最後跑一次 `python "${CLAUDE_PLUGIN_ROOT}/scripts/kb.py" turn note "<白話一句>"`，一句講完全部改了什麼；再跑會蓋掉前一次。
- 不自己讀寫 `.system/sources.json` 與 `.claude/settings.json`，一律經 `kb folders`。
