# kb source-edit 參考

## 共通

- 叫法：`python "${CLAUDE_PLUGIN_ROOT}/scripts/kb.py" source-edit <子子命令> …`，代換不了時用開場段的 kb 指令前綴。
- 要動的東西四種寫法：卡編號（`f-…`、舊的 `out-…`，從卡的檔頭或 `cards list --json` 拿）、清冊 uri（`file://<別名>/<相對路徑>`）、
  `where` 印的「別名/相對路徑」、路徑。夾也收這三種（不用編號）。
- 都可以加 `--json`（帶編號與 uri）；人讀的輸出不印編號，照轉述就好。`move`、`rename`、`trash` 收 `--check`：只算不動。
- exit code：0 做了；3 拒絕、什麼都沒動，第一行是原因，照下面「拒絕」那一列做，不改用別的工具自己做；
  2 參數寫錯（印 usage），對照本頁改參數再跑；其他（印出 Traceback）轉述、說這次沒有動到，不重試。

## move：搬一份檔或一個夾

`source-edit move "<檔或夾>" --to "<夾>" [--check] [--replace]`

- 准許：從登記且讀得到的來源、實體夾（綜合卡以外）、AI 產出、收件匣搬出；搬到登記且讀得到的來源裡已有的夾，或實體夾 `<型別>/<名稱>/`。
- 成功：`已搬好：信義王合約.docx 從 案子 搬到 2026；卡跟著改了（說「退回」會搬回去）`（還沒有卡的沒有「卡跟著改了」）；
  夾：`已搬好：信義王（23 份）從 案子 搬到 2025 封存；不讀的「私人」跟著搬（說「退回」會搬回去）`。兩邊夾名一樣時印「別名/相對路徑」
  （`從 客戶案件/大安陳 搬到 報價與合約/大安陳`）。照念。
- `--check`（整個夾一定先跑；一份檔不確定時也可以）：
  ```
  要搬：信義王（23 份，卡 20 張）從 案子 搬到 2025 封存
  裡面不讀的夾：私人
  目標已經有「信義王」
  可能有檔開著：~$報價.docx
  3 份只在雲端，搬出 OneDrive 會先全部下載（約 120.5 MB）
  ```
  一份檔的第二行是 `卡會跟著改` 或 `這份還沒有卡`；只在雲端的多一行 `這份只在雲端；同一個 OneDrive 裡搬不會下載`。影響要不要先講、要不要先問，我自己判斷；
  有「目標已經有」就照下面「同名」做；有「可能有檔開著」先請她關掉 Word、Excel。
- **同名**：拒絕 `目標已經有「X」`。搬的是一份檔、目標那個也是檔：問她舊的要丟進資源回收筒取代、還是換個名字；
  要取代先跑 `source-edit trash "<目標夾裡那份>" --check` 講舊的那份後果，她明確說取代才加 `--replace`
  （程式先驗過搬得過去才把舊的丟回收筒），成功句下面多一行 `原本的「X」丟進資源回收筒了`（舊的有卡就接 `，卡拿掉了`）。
  搬的是夾、目標那個是夾、或是 rename 撞名，`--replace` 不收，只能問她換個名字。
  舊的丟了、這份卻沒搬過去：`原本的「X」已經丟進資源回收筒，要從那裡拿回來；這份沒搬過去（…），還在原位`，照念。
- **跨硬碟**：拒絕 `不同顆硬碟不代搬；可以幫你打開兩個夾自己拖：kb source-edit open "<來源夾>" "<目標夾>"`（夾名有 $ 或反引號時那兩個路徑是單引號）；
  夾名特殊到指令給不出來時是 `不同顆硬碟不代搬，請在檔案總管自己拖；…請先改夾名`，照念。
  照那個 `open` 打開兩個夾，請她把檔拖過去；拖完下次整理時卡會跟著走。
- AI 產出的定稿搬進她的夾，出處照樣是 AI 產出；收件匣的檔搬進來源夾也一樣跟上。

## rename：改檔名或夾名

`source-edit rename "<檔或夾>" "<新名字>" [--check]`

- 新名字可以不寫副檔名，程式接原本的（「2026.10 報價」「Dr. Wang」這種名字裡的點也一樣補）。新名字的尾巴是另一種檔的副檔名才拒絕：
  `副檔名不改：.docx → .pdf`，跟她說換格式要另做一份（produce）。
- 成功：`已改名：合約.docx → 信義王合約_簽約版.docx（說「退回」會改回來）`；`--check` 印 `要改名：合約.docx → 信義王合約_簽約版.docx`。

## trash：丟進資源回收筒

`source-edit trash "<檔>" [--check]`

- 一定先 `--check`，照三行講，再問；她明確說「刪」「丟掉」才做，「好」「嗯」再問一次：
  ```
  要丟進資源回收筒：舊備忘.docx（案子\信義王）
  那張卡會拿掉；綜合卡要更新：信義王
  說「退回上一版」救不回來，刪錯要從資源回收筒拿
  ```
- 第三行是 OneDrive 時換成：只在雲端的 `這份只在雲端：會從你所有裝置一起刪，要救得到 OneDrive 網頁的回收筒`
  （個人帳號 30 天、公司或學校 93 天內）；OneDrive 裡的本機檔 `刪錯要從資源回收筒拿；別台電腦與 OneDrive 上的那份也會一起刪`。照念。
- 第二行也可能是 `這份沒有卡`、`同一份內容在別處還有，卡留著`（卡不動，只拿掉這個位置）。
- 成功：`已丟進資源回收筒：舊備忘.docx；卡拿掉了`；OneDrive 本機檔後面接 `；別台電腦與 OneDrive 上的那份也一起刪了，刪錯要從資源回收筒拿`；
  只在雲端的是 `已刪：舊備忘.docx；卡拿掉了；這份只在雲端，從你所有裝置一起刪了，要救得到 OneDrive 網頁的回收筒`。沒有卡的沒有「；卡拿掉了」。照念。
  卡、清冊、待處理、從它抽的推測日程程式都處理好了，不用再問「是不是刪了」。
- 退回那一句：卡與清冊回來，但檔在資源回收筒，要她自己從回收筒還原；還原後下次開對話就對上。
- 只收檔：`整個夾請在檔案總管刪`，照念。

## where：這個實體的檔放在哪些夾（只讀）

`source-edit where --entity "<名稱>" [--card-type "<卡型>"]`

```
信義王的檔放在：
- 報價與合約/信義王：5 份（報價 3、合約 2），最近 2026-08-03
- 知識庫/案子/信義王/往來文件：4 份（報價 1、照片 3），最近 2026-10-15
```

- 怎麼讀：份數多、最近才放、卡型跟這份一樣的夾，通常就是她現在放這類檔的地方；最近改了放法的話以最近的為準。
  推薦的去處可以是來源夾的最上層（例：`報價與合約`），不一定要是子夾。
- 推薦一個夾並問一句（「放到報價與合約/信義王 好嗎？」）；她說好就 `move`。推薦只是預設答案，她說別的夾就照她的。
- 只看某種卡型加 `--card-type "<卡型>"`。沒有掛任何檔：`信義王還沒有掛任何檔`。沒有實體的就問她放在哪個主題的夾、叫什麼。
- 實體沒登記：`實體清單沒有「X」，先 kb entity add`。名字可能只在 `cards todo` 的待確認裡、還沒登記，照實說「這個名字還沒登記，
  查不到它的檔放在哪」，改用 `folders find "<名字>"` 找同名的夾，或直接問她要放哪；不自己 `entity add`。

## open：在檔案總管打開夾

`source-edit open "<夾>" ["<夾>"]`：最多兩個；只開不寫。成功印 `已打開：A、B`。

## 拒絕與怎麼跟客戶說

| 第一行 | 怎麼做 |
|---|---|
| `「X」沒有登記，要先把它加進來才能搬過去` | 「X 還不在我讀的資料夾裡；要先把它加進來嗎？」要就照 sources.md 的 add，加好再搬。 |
| `「X」設成不讀，不搬進去也不搬出來` | 搬的是整個夾、要搬進知識庫、X 是裡面的子夾：「X 你說過不讀，搬進知識庫就守不住；要搬請先把 X 移出來。」其他：「X 你說過不讀，我不碰它；要搬請在檔案總管自己搬，不要放進知識庫。」 |
| `不搬進「X」；要放哪個夾跟我說` | AI 產出、收件匣不當目的地；問她要放哪個夾。 |
| `「X」是知識庫自己用的地方，不搬進去也不搬出來` | 「那是知識庫自己用的地方，不能動。」 |
| `整個實體夾的改名或換型別用 kb entity`、`整個型別夾的改名用 kb profile type` | 這是實體改名或換型別，照 note 的做法問她。 |
| `整個登記的資料夾換位置用 kb folders relocate` | 照 sources.md 的 relocate 做（她已經搬好了才用）；還沒搬就請她在檔案總管搬，搬完跟我說。 |
| `這個檔名像密碼或金鑰，不動` | 「檔名像密碼或金鑰的檔我不碰；要搬請在檔案總管自己搬。」整個夾搬進知識庫時，裡面有這種檔也擋：請她先把那些檔移開，或夾留在來源裡。 |
| `「X」跟綜合卡同名，換個名字` | 問她換什麼名字，再 rename 或搬。 |
| `「X」已經在「Y」裡了` | 「它已經在 Y 裡了。」 |
| `有檔開著（X），關掉再試` | 「X 正開著，請關掉 Word、Excel 或預覽再說一次。」什麼都沒動。 |
| `資源回收筒用不了（X），沒有刪` | 「這台的資源回收筒用不了（X），我不直接刪；要刪請在檔案總管自己刪。」 |
| `這份 …，資源回收筒放不下，刪了救不回來；要刪請在檔案總管自己刪`（大小照程式印的，MB 或 GB） | 照念。 |
| `資源回收筒用不了（隨身碟或網路磁碟），沒有刪` | 隨身碟、網路磁碟丟回收筒可能直接永久刪，所以不做：「要刪請在檔案總管自己刪。」 |
| `這份是唯讀的，先取消唯讀再刪` | 「這份設成唯讀了；在檔案上按右鍵→內容，取消唯讀再跟我說。」 |
| `這種名字知識庫不會讀，換個名字` | 新名字或目標夾是 . 或 ~$ 開頭、或隱藏的：問她換個名字或換個夾。 |
| `沒有動：…` | 搬到一半出事已經放回原位：照念原因，請她稍後再說一次。 |
| `已搬好，但後面沒做完；說「退回」可以退回` | 照念；她說退回就照退回做，不自己補。 |
| `找不到這個檔：…`、`找不到這個夾：…` | 請她從檔案總管貼路徑，或說是哪一份，我再找卡。 |
| `新名字不能是空的…`、`不能把夾搬進它自己裡面`、`一次最多開兩個夾` | 照念，問她要怎麼改。 |
| `等不到鎖，沒有動`、`狀態檔讀不到` | 「這次沒有動到，請稍後再試；還是不行請服務人員看。」 |
| `這裡不是知識庫` | 「程式找不到知識庫，請在總資料夾開對話。」停下來。 |
