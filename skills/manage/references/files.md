# kb source-edit 參考

## 共通

- 叫法：`python "${CLAUDE_PLUGIN_ROOT}/scripts/kb.py" source-edit <子子命令> …`，代換不了時用開場段的 kb 指令前綴。
- 要動的東西四種寫法：卡編號（`f-…`、舊的 `out-…`，從卡的檔頭或 `cards list --json` 拿）、清冊 uri（`file://<別名>/<相對路徑>`）、
  `where` 印的「別名/相對路徑」、路徑。夾也收這三種（不用編號）。名字有特殊字元時，kb 給的指令用 `%` 編碼的 uri 寫法，照用。
- 都可以加 `--json`（帶編號與 uri）；人讀的輸出不印編號。`move`、`trash`、`rename` 收 `--check`：只算不動。
- exit code：0 做了；3 拒絕、什麼都沒動，第一行是原因，照下面「被擋時怎麼接著做」接著做完，不用念給客戶；
  2 參數寫錯（印 usage），對照本頁改參數再跑；其他（印出 Traceback）講一句這次沒有動到，自己再試一次，還是不行照核心規則 R-12。
- **共用夾**（登記時 `--shared`，同事也在用）：裡面改名、刪檔、搬檔先告知一句再做，例：「這個夾同事也在用，我把舊報價丟回收筒了，要找回說一聲」。AI 的草稿不放共用夾。

## move：搬一份檔或一個夾

`source-edit move "<檔或夾>"… --to "<夾>" [--contents] [--name "<新名>"] [--replace] [--check]`

- 目標可以多個；`--to` 收客戶任何一個夾（登記的來源、實體夾 `<型別夾>/<名稱>/`、暫存區、知識庫裡客戶自己的夾；型別夾前面有編號，例：`01 案子/信義王/`）；
  `--contents` 只搬夾裡的東西、空了的原夾拿掉；`--name` 搬過去順便改名（只收一個目標）。綜合卡與 willy 自己的區不搬。
- 成功：`已搬好：信義王合約.docx 從 案子 搬到 2026；卡跟著改了（說「退回」會搬回去）`；夾：`已搬好：信義王（23 份）從 案子 搬到 2025 封存；…`。
  做完用一句話講搬了什麼、可以改回，不逐字念。
- `--check`（整個夾、搬出 OneDrive 這類影響大的先跑，其他不用）印要搬幾份、卡幾張、裡面不讀的夾、可能開著的檔、只在雲端的份數。
  有「可能有檔開著」照 `OPEN` 那列做。
- **同名**（`conflict`：`name`、`dest`、`same_content`、`existing`）：內容一樣不用搬；不一樣由你判斷（D-309）：日期或期間不同（每月同名報表）是另一份，
  `--name` 帶期間另存；同一期間改過才是新版，加 `--replace`（舊的先丟進資源回收筒，成功句多一行），說一聲。搬的是夾、目標也是夾，`--replace` 不收，用 `--name`。
- **跨硬碟**：照搬；程式先複製過去、比對一樣才把原檔丟進資源回收筒，中途失敗原檔還在。
- 暫存區的檔搬進客戶的夾，出處照樣跟上。`--to` 是登記實體的 `<型別夾>/<名稱>`（`案子/信義王` 也收）而夾還沒建，程式先建。
  從 `暫存區/<來源>/` 搬出定期交來的檔：清冊記著新位置，下次交來直接更新那裡，不用另外處理。

## rename：改檔名或夾名

`source-edit rename "<檔或夾>" "<新名字>" [--check]`

- 新名字可以不寫副檔名，程式接原本的。新名字的尾巴是另一種檔的副檔名才拒絕：`副檔名不改：.docx → .pdf`，換格式要另做一份（produce）。
- 成功：`已改名：合約.docx → 信義王合約_簽約版.docx（說「退回」會改回來）`。

## trash：丟進資源回收筒

`source-edit trash "<檔或夾>"… [--permanent] [--check]`

- 客戶說刪、丟掉就直接做，不先講後果、不多問；一次可給多個，整個夾也收，空夾直接拿掉，唯讀的先取消唯讀。做完講一句「丟進資源回收筒了，要找回說一聲」。
  卡、清冊、待處理、從它抽的推測日程程式都處理好了。
- 只在 OneDrive 裡才多講：本機檔「別台電腦與 OneDrive 上的那份也一起刪了」；只在雲端的「從你所有裝置一起刪了，要救得到 OneDrive 網頁的回收筒」。
- 進不了回收筒（隨身碟、網路磁碟、檔太大）：程式先留一份進回合備份再刪，照做。只有「這台電腦連備份都放不下」的句子（`NO_ROOM`）才用白話問：
  「刪了就救不回來，確定要刪嗎？」客戶說確定才加 `--permanent`。
- 退回那一句：卡與清冊回來，檔在回收筒的由程式放回，在備份裡的照原位放回；隨身碟沒插著先請客戶插上。

## where：這個實體的檔放在哪些夾（只讀）

`source-edit where --entity "<名稱>" [--card-type "<卡型>"]`

```
信義王的檔放在：
- 報價與合約/信義王：5 份（報價 3、合約 2），最近 2026-08-03
- 知識庫/01 案子/信義王/往來文件：4 份（報價 1、照片 3），最近 2026-10-15
```

- 怎麼讀：份數多、最近才放、卡型跟這份一樣的夾，通常就是她現在放這類檔的地方；推薦的去處可以是來源夾的最上層。
- 看得出去處就直接搬、說一聲放哪；兩個夾差不多才問一句。她說別的夾就照她的。
- 只看某種卡型加 `--card-type "<卡型>"`。沒有掛任何檔：`信義王還沒有掛任何檔`。沒有實體的看檔名內容判斷放哪個主題的夾，猜不到才問。
- 實體沒登記：`實體清單沒有「X」，先 kb entity add`。名字可能只在 `cards todo` 的待確認裡，改用 `folders find "<名字>"` 找同名的夾，或直接問她放哪。

## open：在檔案總管打開夾

`source-edit open "<夾>" ["<夾>"]`：最多兩個；只開不寫。成功印 `已打開：A、B`。客戶要自己看一眼時才用。

## 被擋時怎麼接著做

| 第一行 | 怎麼做 |
|---|---|
| `「X」使用者說過不讀，不搬進去也不搬出來。` | 這件不動 X，其他照做；回答講一句「X 你說過不讀，沒動它」。客戶要重新納入跑 `kb folders include <路徑>`。 |
| `「X」是知識庫自己用的地方，不搬進去也不搬出來` | 改搬到客戶的夾；不跟客戶講這句。 |
| `這個檔名像密碼或金鑰，不動。` | 這個檔不動，講一句原因；其他檔照做。 |
| `「X」跟綜合卡同名，換個名字` | 自己換個名字（加日期或描述）再 rename 或搬，說一聲。 |
| `「X」已經在「Y」裡了` | 已經在那，不用做，回答說一聲就好。 |
| `「X」開著，關掉才動得了` | 客戶自己的檔開著：一步一步講「把 Word（或 Excel）裡的 X 存好關掉，關好跟我說」；不要替他關。其他檔照做。 |
| `資源回收筒用不了…`、`這份 …，資源回收筒放不下` | 程式會先留備份再刪；出現 `NO_ROOM` 句才照上面問一句。 |
| `這種名字知識庫不會讀，換個名字`、`這種名字 Windows 不收，換個名字` | 自己換個名字再做，說一聲。 |
| `沒有動：…` | 搬到一半出事已經放回原位：講一句沒動到，自己再試一次。 |
| `已搬好，但後面沒做完；說「退回」可以退回` | 跑 `kb versions undo` 改回那一步，再做一次。 |
| `原本的「X」已經丟進資源回收筒…這份沒搬過去` | 舊的在回收筒：把這份用 `--name` 另取名搬過去，或從回收筒拿回來，說一聲。 |
| `找不到這個檔：…`、`找不到這個夾：…` | 用 `folders find`、`folders locate` 或卡找；找到接著做，找不到才問她是哪一份。 |
| `新名字不能是空的…`、`不能把夾搬進它自己裡面`、`一次最多開兩個夾` | 自己改參數再做。 |
| `等不到鎖，沒有動` | 自己再試一次；還是不行照核心規則 R-12。 |
| `這裡不是知識庫` | 到知識庫資料夾裡再跑；對話沒開在總資料夾時請客戶在總資料夾開對話。 |
