# 整個知識庫的操作參考（備份、還原、清空間、換位置、換電腦、換帳號、升級）

## 共通

- 叫法同本 skill 本文：`python "${CLAUDE_PLUGIN_ROOT}/scripts/kb.py" <子命令> …`。都收 `--json`；人讀輸出不印編號與回合代號，照轉述。
- exit code：0 做了（或只是查）；3 拒絕或沒做成，第一行就是原因，照下面「常見拒絕」那一列接著做（表裡沒有的：照訊息換做法接著做，真的做不到才照 R-12 講）；2 是不在知識庫裡（`不在知識庫裡：…`）；其他（印出 Traceback）自己再試一次，還是不行才請服務人員（程式出錯）。
- 這些都只管知識庫裡的東西；她原本登記的資料夾（原檔）不在備份裡，要她自己的備份顧（問「備份裡有我的原始檔嗎？」就這樣答）。
- 備份、還原、清理、`moved` 做了什麼，程式自己記進工作日誌（對話裡併進那一句，終端機跑的記一段），不用跑 `kb turn note`（R-13）。

## 退回與還原怎麼分

- 「上一步、剛剛、昨天那次整理」是**改回**（`kb versions undo`，R-05）：說得出是哪一步（「第一句那個名字改回來」）就直接 `undo <項目編號>`，整句都退用 `undo <回合代號>`；分不出才 `kb versions items` 列出來問（印的就是「10-23 14:05 那句「…」」，照念、不唸代號）；單說「退回」是 `kb versions revert`，等於退最近一句。`undo` 回 `conflict`（那一項之後又被動過）的不硬做，看 `then`、`later`、`now` 判斷，改成客戶要的樣子或問一句；做完只講改回了什麼，沒動的項目不用提。「備份、那一份、整個回到某天」是**還原**。
- 「升級後怪怪的、退回舊版」是**換回舊版**（`kb upgrade --downgrade`，見 upgrade）；升級前的快照只經它用，不直接 `restore apply`（plugin 還是新版，格式會對不上）。
- 分不清（例如「回到昨天」）就問一句：「是退回剛剛那一步，還是回到某一天的備份？」剛升級過的再加第三個選項：「退回剛剛那一步、回到某一天的備份、還是退回升級前的舊版？」
- 退回超過保留期退不回：最早能退到哪一句看 `versions clean --check` 印的「最早還能退回到 …」；有備份就提還原。

## backup：備份整個知識庫

`backup [--to "<夾>"] [--check]`

- 第一次沒記過放哪：`backup --check --json` 的 `need_to` 是 true（人讀 `backup` 印 `還沒說備份要放哪`、exit 3）。問她放哪（隨身碟、OneDrive、Dropbox、其他磁碟；不收網路位置，`\\` 或 `//` 開頭的路徑會被拒絕，NAS 請她先對應成磁碟機），
  `--to "<夾>"` 帶上再跑，程式記住；之後不用再給，換位置也是 `--to`。
- `--check --json`：`to`、`need_to`、`files`、`bytes`、`sync_folder`、`refuse`；一律 exit 0。`sync_folder` 是 true 說一句：
  「放在雲端同步的夾，會上傳到雲端，第一次比較久。」`refuse` 有字就照下面拒絕表講，不去跑。
- 成功：`備份好了：<路徑>（1234 份、30 MB）；那裡留最近 3 份。`，下一行接清理那句（見 clean）。照念；她問到才講備份只包知識庫。
- 同一天再做會是 ` (2)`；那個夾裡別人的檔、別個知識庫的備份不碰，只替我們做的備份留最近 3 份。
- 排程是另一題（B-522）：問「每天自動備份」就記下客戶想要，現在先說「幫我備份」就做。

## restore：還原（先演練、說好才做）

- `restore list [--from "<夾>"]`：這台電腦記的備份夾與 `--from` 的，加知識庫裡的快照，新的在前。人讀一行一份：`10-15 14:05｜備份｜LIN-PC 做的｜30 MB`
  （不能用的後面接 `｜不能用：原因`）。要路徑與名字取 `--json`（`name`、`path`、`kind`、`created`、`machine`、`bytes`、`usable`、`why`）。
  客戶說「上禮拜那份」就從日期找；找不到就請她用 `--from` 指備份夾（空資料夾還原、備份在隨身碟時）。
- `restore check "<zip 路徑或快照名>"`：**只讀**，不動任何東西。先講完再問，她說好才 `apply`。
  - 第一行 `會回到 10-15 14:05 的樣子`，接 `這份是 LIN-PC 做的備份`；再一類一行，只列有的：`口述：會不見 3 條（「…」、「…」）；會回來 1 條`；
    類別有口述、裁示、日程、推算、實體、檔案卡、綜合卡、AI 產出、工作日誌；最後 `你原本的資料夾不會動`。綜合卡的「會不見」包含內容不同的，講成「會變回舊的版本」。
    `這幾個知識庫自己的設定檔會變回那份的樣子…：CLAUDE.md` 那行也要講（她改過 CLAUDE.md 的話，改的會回到那份的樣子）。
  - 怎麼講：「會回到 10 月 15 日下午的樣子。這段時間記的口述 3 條、日程 2 條會不見（例如『信義王的設計師換成小陳』），你原本的資料夾不會動。要還原嗎？」
    數字照程式、例子照程式，不自己估；一類都沒有就說「跟現在幾乎一樣」。
  - 多一行 `你設成不想讓 AI 看到的「X」會留著，還原後再清一次`：照講。多一行 `建置會回到做到一半的…那一步`：照講，下次打 build 接著做。
  - 擋住時第一行是原因（exit 3），照下面拒絕表講。
- `restore apply "<zip 路徑或快照名>"`：先拍快照（還原前）、解開驗過、換進去；失敗全部移回、什麼都沒動。
  成功：`已還原到 10-15 14:05 的備份；說「剛剛的還原不要了」可以回到還原前。還原後有 N 份要重新整理。` 照念；N 大於 0 說「還原後開場會看到變動，照常整理就好」。
  沒有還原前快照時（空資料夾，或現在有還沒清完的不想讓 AI 看到的夾、快照整包清掉了）第一句改成 `…這次沒有還原前的快照，回不到還原前。…`，照念、不說「還原不要了」。
  她新增的原檔沒動。後面可能多幾行，照講：`你設成不想讓 AI 看到的「X」留著、也再清了一次`（這夾的卡、清冊條目都會拿掉；那時 `--json` 的 `snapshot` 還在就是還原前快照留著，null 就是清掉了，句尾多 `（還原前的快照也一起清掉了）`）、
  `不想讓 AI 看到的夾還沒清完：…`（照 `references/sources.md` 的 purge 做）、`建置停在「X」那一步，下次打 build 從那裡接著做`、`還原好了，但有一步沒做完：<哪一步>（原因），<怎麼補>`（換進去已經成功，只是後面補骨架之類那步沒做完：照念，先說還原好了、再說哪一步與怎麼補）。「沒做完」的句子都是「沒做完：<哪一步>（原因），<怎麼補>」這個順序。
- **「剛剛的還原不要了」**（退回舊版造成的還原前快照不走這條）：`restore list --json` 取最新的、`kind` 是 snapshot 而且名字帶「（還原前）」那份，一樣先 `check` 講、說好才 `apply <快照名>`。
- **知識庫整個被刪**：先請她看資源回收筒；沒有就在原位置開一個空資料夾、在那裡開對話，`restore list --from "<備份夾>" --json` → 拿那一份的 `path` 給 `check`、`apply`（空資料夾裡只收完整路徑，不收檔名）。
  桌面版這次會跳「允許嗎」，請她按允許。沒有備份就照實說救不回，原檔還在，可以重新建置。
- 有知識庫時還原不覆蓋這台電腦的知識庫編號與位置紀錄；空資料夾還原用備份裡的位置紀錄，開場看到「換了位置」或「第一次開」才跑 `kb moved` 補，沒看到就不用。
- `check` 多一行 `這份是另一個知識庫的備份，不是這個知識庫自己的`（`--json` 的 `other_vault` 是 true）：先跟她說「這份是另一個知識庫的備份」，再問要不要繼續；她說要才 `apply`（照樣放行）。

## clean：空間不夠、清放太久的備份

`versions clean [--check]`（備份做完會自動接著跑；說「C 槽快滿了、知識庫怎麼越來越大」先 `--check` 講，她說好才不帶 `--check` 跑：清掉的回合備份就退不回了）

- 回合備份超過 30 天或 200 個就從最舊的清，至少留最近 20 個；快照留 2 份；正在做的不清。
- 成功：`清掉 12 個回合備份、1 份快照，空出 8 MB；最早還能退回到 09-23 10:02 那句「把這份合約存起來」。`；沒得清：`沒有要清的；最早還能退回到 …`。
  `--check` 同格式、不動。講：清掉什麼、空出多少、最早還能退回到哪一句，照程式的數字講，不自己判斷空間被誰佔。
- 問「多久自動清一次」：備份做完會清，說空間不夠也能當場清；沒有排程。

## moved：換了位置、換了電腦

開場出現 `知識庫換了位置：…` 或 `這台電腦第一次開這個知識庫：…` 就跑 `moved`（只是把舊路徑換新路徑，不用先問）；想先看再做才用 `--check`。

- `--json`：`state`（same｜moved｜new_machine｜first）、`from`、`to`、`sources_rewritten`、`missing_sources`、`old_copy`、`env`、`passwords_missing`。
- 人讀一行一件（沒有要補的是 `位置沒變，沒有要補的`、第一次是 `第一次看這個知識庫，位置記下了`），照著逐件處理：
  - `來源「X」的位置換成新的了`：講一句做了什麼；說「退回」換得回來。
  - `這台找不到的來源：A、B`：一個一個 `kb folders locate <別名>` 自己找，找到就 `kb folders relocate` 接上（`references/sources.md`）、說一聲；找不到才問她搬到哪了。
  - `舊位置還有一份：<路徑>；確認新的沒問題就把舊的刪掉`：問一句要不要丟掉，說好就 `kb source-edit trash`。
  - 換電腦時多的幾行是這台缺的元件（照那句講、跑它給的指令）與「憑證管理員沒有這些密碼，要重新記」：密碼不會跟過來，請她逐個重說（走 note 的 `kb unlock`）。
- 她要搬整個知識庫時是唯一在開著的對話裡做不到的（R-07），**一步一步帶**：先關這個對話；在檔案總管把整個資料夾剪下、貼到新位置；在新位置開對話，開場會自動補。每一步做完說一聲再下一步。
- 換電腦：Python、plugin 自己裝（`winget install Python.Python.3.12`，跳出系統管理員視窗請客戶按「是」，裝完請客戶關掉 Claude 重開）；只有 Claude 本身請客戶裝；知識庫用備份還原（推薦）或直接拷資料夾；第一次開對話跑 `moved`，一次列出要補的。

## 換帳號

`output links [--json]`（只讀）：列存成連結的線上文件，一行 `標題（日期）`；沒有印 `沒有存成連結的線上文件`。講三件事（只講一次，之後客戶問才講）：

1. 知識庫與 plugin 不受影響，照常用。
2. 舊帳號做的線上文件，網址在新帳號打不開：請她在舊帳號分享給新帳號，或下載成檔、放進知識庫（下載的檔怎麼掛回去看 produce）。
3. 隱私設定、外部服務（連結的其他服務）要在新帳號重設。

最後固定說一句：**舊帳號處理過的資料不會因為換帳號而刪掉。**

## 舊電腦送人（代做）

先問一句備份要不要留，再代做：知識庫資料夾用 `kb source-edit trash` 收、移除 plugin（claude plugin 指令，不行再一步一步帶她到外掛畫面按）、
刪 `%LOCALAPPDATA%\wiki-with-willy\` 工具夾、憑證管理員裡 `wiki-with-willy/` 開頭的那幾筆（`kb unlock forget`）。她原本的原檔另外處理。

## upgrade：升級、有新版嗎、退回舊版

`upgrade [--check] [--finish] [--downgrade] [--json]`、`upgrade skeleton <相對路徑> --keep|--replace`。開場那行只是上一次背景查到的結果；她問「有新版嗎」才當場查。開場那行每個版本只講一次。

- **有新版嗎**：`upgrade --check --json`：`plugin`（現在跑的）、`vault`（知識庫最後升到哪版）、`latest`、`kind`（patch｜minor｜major｜downgrade｜none，連不上是 null）、`allowed`（她在不在名單上，不在就當沒有新版）、`note`（一句話）、`snapshot_for_downgrade`、`restore`（只有退回才有）、`error`。
  人讀：`現在 0.20.1；最新 0.21.0（日程可以匯出成 Excel），說「升級」就幫你升。`／`目前是最新版（0.20.1）。`／`現在連不上更新的地方，晚點再問。`（連不上不是出錯，exit 0）。被問「現在是哪一版」就念 `plugin` 與 `vault`。
- **升級**：她說「好，升級」才跑 `upgrade`（R-07）。先講：「要先拍一份升級前的快照，要等一下；換好之後請你開一個新對話，新對話才是新版。」成功 `好了，開一個新對話就是新版（0.21.0）。` 照念，請她開新對話；這個對話不再做別的事（舊程式讀寫新格式的檔會出錯）。
  小修（`kind` 是 patch）不用講快照、成功句一樣請她開新對話；多半背景已經自己換好，下一個對話開場說一句。她自己在畫面上按更新跳「覆寫本機變更」是假警報，按「仍要更新」；Claude 說有更新也要按。`/reload-plugins` 省不掉開新對話（桌面版確認驗過：同一個對話還是舊版），一律請她開新對話。
  擋住的話（`背景整理還在跑，先停掉再升級`、`另一個備份、還原或退回正在跑…`）照下面拒絕表做。
  回 `新版 X 在這台電腦跑不起來（…）`（`upgrade`，或 `--check` 多的那一行）時照句子講，說我們修好會再發；不要叫她重試或自己換。回 `現在下載不到新版，晚點再說一次；什麼都沒動` 是暫時抓不到（網路、太慢），請她晚點再說一次「升級」。
- **新對話開場有 `已換到 X：先跑 kb upgrade --finish 再做別的。`**：先 `upgrade --finish`（幾秒、不用問她），再回答她的問題。第一行 `已升到 0.21.0：一句話`（小修 `已自動套用小修正 X：…`）照念一句；
  之後一行一件（`轉成新格式：…`、`卡的檔頭跟上了 N 張`、`補上骨架：…`、`骨架換成新版：…`、`沒轉成：…（原因）`）講做了什麼；再跑會回 `已經是 X`；`--check` 多一行「知識庫還停在 X」就是還沒轉格式，等新對話開場做。「這次升級改了什麼」就念那句一句話，要展開從 CHANGELOG 那一版講；卡只換檔頭欄位、正文不重做。
- **骨架檔要問她**：最後一行 `要問她：…`（`--json` 的 `skeleton_ask`）是她改過、新版也改了的檔。問：「你改過知識庫裡的「CLAUDE.md」，新版也改了它：保留你的、換成新的、還是兩個都看？」她選了才 `kb upgrade skeleton "<檔>" --keep`（留她的）或 `--replace`（換新，她那份備進回合、說「退回」就回來）；成功句照念，沒選前不動。
- **開場有 `上次升級到 X 還沒換好；說「升級」我再試一次。`**：上次升級記下了卻沒換成；她說「升級」就再跑 `upgrade`（沿用上次的快照，不會多拍一份）；還是不行先跑 `kb selftest` 看原因，程式出錯才請服務人員。
- **「不要自動更新，我怕壞掉」**：大升級一定要她說好才做；小修（只修錯、不改格式）會自己套用，下一個對話開場說一句。
- **退回舊版**（「升級後怪怪的」、開場有 `這一版 X 撤回了…`）：先說我們會修、小修發出來會自動補上；她等不及或真的不能用才退：`upgrade --check --json` 的 `kind` 是 downgrade、`snapshot_for_downgrade` 有值，`restore` 欄是演練結果，照「還原」那段講會不見什麼（升級後記的口述、日程會不見，她原本的資料夾不會動）；說好才 `upgrade --downgrade`，
  成功 `已回到 0.20.1 的知識庫，也換回 0.20.1；開一個新對話就好。`。快照沒了回 `升級前的快照已經不在，不能退回；請服務人員幫忙`（保護壞了，D-319），不降版（`--check` 已經說不能退回就別再跑 `--downgrade`）。
- **升級到一半當機**：快照拍到一半就重跑 `upgrade`；換版之後當機，新對話開場照常 `upgrade --finish`。
- 給客戶唸的只有版號與一句話；不唸快照檔名、回合代號、`pending`、schema 這些。

## 常見拒絕與怎麼接著做

| 第一行含 | 怎麼做 |
|---|---|
| `還沒說備份要放哪` | 問她放哪（隨身碟、OneDrive、其他磁碟），帶 `--to` 再跑。 |
| `備份不能放在知識庫裡面` | 自己選知識庫外面的夾（沒有就問她放隨身碟或另一個夾），帶 `--to` 再跑。 |
| `備份不能放在登記的資料夾「X」裡` | 自己換一個不在讀的地方，帶 `--to` 再跑。 |
| `那個位置寫不進去` | 隨身碟請她插好（一步一步），或換一個位置。 |
| `空間不夠：要 N MB，那裡只剩 M MB` | 照講數字，請她換個位置或先清空間（還原時還沒動任何東西，連快照都沒拍）。 |
| `背景整理還在跑，先停掉再…` | 照 ingest 的「停」做（`cards stop`），停好再做一次。 |
| `另一個備份、還原或退回正在跑` | 等一下自己再跑一次；還是一樣才跟她說另一個動作還在跑。 |
| `這份不是 wiki-with-willy 的備份` | 換一份（`restore list`）。 |
| `這份備份壞了（…）` | `restore list` 找下一份能用的，說一聲。 |
| `這份備份是比較新的版本（V）做的，先升級再還原` | 先 `kb upgrade --check` 看，她說好就升級 plugin，再還原。 |
| `這個資料夾不是空的，也不是知識庫` | 帶她換一個空資料夾，在那裡開對話。 |
| `有檔案開著（X），關掉再說一次；什麼都沒動` | 請她把那個檔存好關掉（Word、預覽），做完說一聲，再跑；沒有東西被改。 |
| `還原沒做完：有東西沒能移回去（…），還原前的東西放在 …` | 照念那個位置，請她先別刪那個夾、找服務人員；不要自己再還原一次。 |
| `備份要放在這台電腦的資料夾或隨身碟；網路上的位置請先對應成磁碟機` | 改放這台電腦的夾或隨身碟；一定要網路位置就一步一步帶她對應成磁碟機。 |
| `目前是最新版（X）` | 現在就是最新版（X），講一句。 |
| `新版剛出來，幾分鐘後再說一次` | 新版剛發出來，等幾分鐘再自己跑一次；不連續重試。 |
| `這台找不到 Claude 的更新程式…` | 自己找 claude.exe（`%LOCALAPPDATA%`、Program Files），找到就照它的路徑再跑；找不到才請服務人員（新電腦裝 Claude）。 |
| `更新沒成功：…` | 說沒換版、知識庫沒動（拍過快照的留著、沒拍成就沒有），自己稍後再試一次；`這個外掛不是從市集裝的`、`安裝紀錄裡找不到…` 這類不是暫時的，直接請服務人員。退回舊版時下一行寫著「知識庫已經還原」：照念，不要再跑退回，請服務人員接手。 |
| `現在連不上更新的地方，晚點再說一次` | 稍後自己再試一次。 |
| `這一版（X）撤回了；要退回先用 kb upgrade --check …` | 走「退回舊版」那段：先 `--check` 講會不見什麼，她說好才 `--downgrade`。 |
| `這不是骨架檔：…` | 檔名照 `skeleton_ask` 給的重打。 |
| `找不到這份：X` | 跑 `restore list` 自己對；對不上才念給她問是哪一份。 |
| `這裡不是知識庫`、`不在知識庫裡：…` | 請她在總資料夾開對話。 |
| `備份沒有做成：…`、`還原沒有做成：…`、`等不到鎖，沒有寫入`、`狀態檔讀不到或寫不進去：…` | 自己再試一次；還是不行跑 `kb selftest`，程式出錯才請服務人員。 |
