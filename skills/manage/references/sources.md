# kb folders 參考

## 共通

- 叫法：`python "${CLAUDE_PLUGIN_ROOT}/scripts/kb.py" folders <子子命令> …`，代換不了時用開場段的 kb 指令前綴。
- 對話開在總資料夾裡，不加 `--vault`。
- 每個子子命令都可以加 `--json`，印一行 JSON，不印給人的句子。
- exit code：
  - 0：做了。第一行是給人的句子，照轉述。
  - 3：拒絕，什麼都沒寫。第一行是原因，照下面「常見拒絕」跟客戶說，不換方法。
  - 2：參數寫錯（argparse 印 usage）。對照本頁改參數再跑一次。
  - 其他（程式當掉、印出 Traceback）：轉述，說這次沒有改到，不重試。
- 路徑一律加引號；相對路徑以目前目錄（總資料夾）為準。

## add：登記一個來源資料夾

```
folders add "<路徑>" [--alias "<別名>"] [--check]
```

- `--check` 只印報告、不寫；沒有 `--check` 才登記。
- 別名預設是資料夾名，結尾的空白與點會去掉。
- 第一行：
  - `會登記「客戶案件」（../raw/客戶案件，12 份）`（`--check`）
  - `已登記「客戶案件」（../raw/客戶案件，12 份）`
- 之後可能有：
  - `- 其中 3 份檔名像密碼或金鑰，不會讀：客戶案件/帳密.txt、…`（最多列 10 個，多的寫「…還有 N 份」）
  - `- 提醒：<一句>`，可能有好幾行。
- `--json`：`id`（`--check` 時是 null）、`alias`、`spec`、`path`、`files`、`credential_files`（清單）、`warnings`（清單）、`check`。

## `--check` 報告怎麼轉白話

- 份數：「這個資料夾裡有 12 份檔。」
- 檔名像密碼或金鑰的檔：列出檔名（最多 10 個，多的說還有幾份），說「這幾份預設不讀；之後可以一份一份告訴我哪份可以讀。」
- 提醒句照印，不改寫、不省略：
  - 「份數 0，這個資料夾裡沒有檔案」
  - 「這個位置存的是絕對路徑，換電腦會找不到」
  - 「這是整個「Desktop」資料夾，範圍很大，可以只加裡面的某個資料夾」
- 最後問別名：「名字就叫「客戶案件」可以嗎？」客戶要換就用 `--alias`。

## exclude：不讀來源裡的一個夾或檔

```
folders exclude "<路徑>" --kind hidden|unused [--reason "<一句>"]
```

- `hidden`：不想讓 AI 看到。`unused`：用不到。兩種之後都不讀。
- 對象要真的存在，而且在某個登記的來源裡面。
- 第一行：
  - `已排除「行政/薪資」（不想讓 AI 看到）。之前讀過的已送過雲端；這版還沒有卡和備份要清。`
  - `已排除「行政/舊檔」（用不到）。`
- `--json`：`source_id`、`alias`、`spec`（相對來源根）、`kind`、`reason`、`added`。

## remove：拿掉一個來源

```
folders remove "<別名>"
```

- 連它的排除一起拿掉；客戶的檔不動。別名照 `list` 印的，一字不差。
- 第一行：`已拿掉來源「客戶案件」；你的檔案沒動，從現在起不讀它；說「退回上一版」救得回。`
- `--json`：`id`、`alias`、`spec`。

## include：取消排除

```
folders include "<路徑>"
```

- 路徑要跟當初排除的那個夾或檔一樣；在排除夾裡面的檔不算。
- 夾已經被刪掉也可以取消（只比路徑）。
- 第一行：`已取消排除「行政/薪資」，從現在起讀得到。`
- `--json`：`source_id`、`alias`、`spec`、`kind`。

## list：列出登記的來源與排除

```
folders list
```

- 沒有登記：`還沒有登記任何來源`
- 每個來源一行：`「客戶案件」 ../raw/客戶案件 → <完整路徑>`；找不到的結尾加 `（這台電腦找不到）`。
- 排除在來源底下一行一條：`  - 排除 薪資（hidden，薪資個資，2026-10-12）`
- `--json`：`{"sources": [{"id", "alias", "spec", "path", "exists", "excludes": [{"spec", "kind", "reason", "added", "path", "exists"}]}]}`
- 組路徑：`include` 用 `excludes[].path`；`exclude` 用來源的 `path` 接夾名；組不出來就請客戶貼。
- 轉白話時 `hidden` 說「不想讓 AI 看到」、`unused` 說「用不到」。

## 常見拒絕與怎麼跟客戶說

第一行含什麼 → 怎麼做。「」裡是跟客戶說的話；由上往下找，先對到的算。

| 第一行含 | 怎麼做 |
|---|---|
| `sources.json 讀不了`、`等不到`、`沒有寫入` | 轉述那一行，說「這次沒有改到，請稍後再試；還是不行請服務人員看。」 |
| `找不到 …；排除的對象要真的存在` | 「那個夾或檔找不到，請確認名稱，或從檔案總管貼路徑。」 |
| `找不到 …` | 「這個路徑在這台電腦找不到，請從檔案總管位址列再複製一次。」 |
| `是檔案，不能當來源` | 「要加的是資料夾，請給那個檔所在的資料夾。」 |
| `整顆磁碟不能當來源` | 「不能整顆磁碟加進來，請指定裡面的資料夾。」 |
| `系統資料夾` | 「那是 Windows 的系統資料夾，不能加；請換放工作檔案的資料夾。」 |
| `總資料夾和來源不能互相包含` | 「知識庫自己的資料夾不能當來源，也不能加一個包住知識庫的資料夾。」 |
| `是另一個知識庫`、`裡面有另一個知識庫` | 「那裡是（或裡面有）另一個知識庫，不能加進來。」 |
| `和既有來源「X」重疊` | 「這個資料夾跟已經在讀的「X」重疊；要分開管請在來源裡建子夾。」 |
| `別名「X」已經有了`、`保留字`、`保留的裝置名`、`不能含` | 「名字「X」不能用，換一個好嗎？」客戶給了新名字再用 `--alias` 跑。 |
| `不在任何登記的來源裡` | 「那個夾本來就沒在讀。要先把它所在的資料夾加進來嗎？」客戶說要，照加資料夾的做法。 |
| `已經在排除裡` | 「那個夾已經不讀了，不用再做。」 |
| `整個來源用 folders remove X` | 「這是整個來源；要拿掉整個「X」嗎？檔案不會動。」客戶確認了照拿掉來源的做法。 |
| `沒有叫「X」的來源` | 跑 `list`，把別名念給客戶，問是哪一個。 |
| `不在排除清單裡` | 「那個夾本來就讀得到，不用取消。」 |
| `這裡不是知識庫` | 「程式找不到知識庫，請在總資料夾開對話。」停下來。 |
