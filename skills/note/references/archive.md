# 封存：過時的檔與實體收起來（D-332）

封存是「還找得到，但不再整理、不再問、不拿來答現在的事」。判斷全在你，程式只記。

## 一、什麼時候封存、什麼時候拿回來

- 客戶說「這份過時了」「這批舊報價收起來」「X 不往來了」「不用再管 X」：封存。結案是另一件事（`agenda.md` 第四節的事類狀態），兩者可以並存：結案的案子不一定要封存。
- 客戶說「那份還要用」「把 X 拿回來」：拿掉封存。
- 客戶說過「X 夾是放舊東西的」：記成偏好（`preference.md`，用在全部），之後 ingest 用 `kb changes --moved` 看到檔搬進那個夾，就對那些檔 `kb archive`。

## 二、怎麼做

- 檔：`kb archive <清冊編號或路徑>… --reason "<客戶的話>"`；實體：`kb archive <名稱>…`；可以一次給好幾個，只要有一個認不出，整句都不動，照訊息補上再跑。編號不知道先 `kb find`、`kb lookup` 查。
- 拿掉：`kb archive --undo <目標>…`。
- 之後：整理不列它重做、不從它抽日期，`kb asks`、待處理、健檢不出跟它有關的題；`kb find`、`kb lookup`、`kb cards list` 照樣找得到，結果帶 `archived: true`、排在後面；綜合卡把封存的檔收進「其他」，總目錄把封存的實體收進「已封存」。
- 客戶要把舊檔搬走、又沒有放舊東西的夾：第一次才建 `封存/`，用 `kb source-edit move` 搬進去，說一聲；已經有就用現有的夾。搬進去之後照上面的 `kb archive`。

## 三、回答

講封存了什麼（幾份、哪個實體）、加一句「不對說一聲可以退回」，再照 `agenda.md` 第五節跑 `kb asks`。
