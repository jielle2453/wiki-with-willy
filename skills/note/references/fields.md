# 數字欄：售價、進價這類要算的數字怎麼記

客戶講到某個東西的數字（售價、進價、一箱幾瓶、安全庫存、合約總價）時照這份做（記帳 1b，D-272、D-281、D-307、D-342）。數字的正本在實體上，綜合卡檔頭（Obsidian 屬性欄）由程式顯示；不在卡上自己寫這些行。

## 一、第九節有那一欄

```
python "${CLAUDE_PLUGIN_ROOT}/scripts/kb.py" entity field 精華液 售價=1800 進價=1200 --said
```

- 一次可以給好幾欄；數字照她講的寫（1,800、1.5、3萬都收），不收負數、不收中文數字（「一千八」先換成 1800 再給）。
- 一律帶 `--said`：她說的，之後檔案裡讀到不一樣的也蓋不掉，她再說才改。
- 回答照成功句複述一次（「精華液：售價 1,800 元、進價 1,200 元」），加一句「不對說一聲可以退回」。
- 拒絕說第九節沒有那一欄：照第二節加欄再記。

## 二、第九節沒有那一欄

她講到的數字是這類東西固定有的（「膠囊會員價 1600」）：照 D-307 直接加欄、記值、說一聲，不先問。

```
python "${CLAUDE_PLUGIN_ROOT}/scripts/kb.py" profile add 數字欄 型別=產品 欄名=會員價 單位=元
python "${CLAUDE_PLUGIN_ROOT}/scripts/kb.py" entity field 膠囊 會員價=1600 --said
```

回答說「在產品加了一欄『會員價』」。欄名不能用庫存、累計收、累計付、未收、未付（程式算的），也不能跟同型別的標籤欄同名；被擋就換個說法再加。

## 三、不加欄的

- **一次性的價格**（「這次給她算 1,500」「這批進價特別低」）：不是這個東西固定的數字，不加欄、不改欄；是一筆帳的單價：照 `references/money.md` 第二節寫在那個品項的 `@單價`（帳關著時照第三節記成口述）。
- **算出來的**（庫存、累計收、未收）：不是欄，程式算，不要設。

## 四、清掉

她說不用記了（「膠囊不賣了，售價不用記」）：那欄給空的，算她說的，舊值留著。

```
python "${CLAUDE_PLUGIN_ROOT}/scripts/kb.py" entity field 膠囊 售價= --said
```

整欄都不要了（「產品不用記售價了」）：`kb profile remove 數字欄 型別=產品 欄名=售價`，每個產品的售價一起拿掉（舊值留著），照成功句講影響幾個。

## 五、她在卡的屬性欄改了數字

開場或每句開頭說她在卡的屬性欄改了標籤或數字：跑 `kb entity tag --from-card`（數字一起記，算她說的），照成功句講記了什麼；寫的不是數字（「兩千」）的問她要記成多少，照她答的用第一節記。

## 六、平常在哪（多人共用）

成員說「我調到南店了」：改設定檔第五節她那列的平常在哪。

```
python "${CLAUDE_PLUGIN_ROOT}/scripts/kb.py" profile add 關於你 名稱=小王 平常在哪=南店
```

南店要是第十節「地點的型別」的實體；第十節還沒寫地點的型別時，先 `kb profile add 記帳 地點的型別=分店` 補上、說一聲。
