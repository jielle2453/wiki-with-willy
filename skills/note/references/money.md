# 錢的話怎麼記

設定檔的偏好說錢的事交給別的工具（例如另外裝的記帳），就照偏好，不記口述。

客戶講到收、付、賣、進貨、欠、尾款、繳費、盤點、墊錢、調貨，或售價、合約總價這類數字時照這份做。她講的錢一律記成口述加記號（D-343）；講到人或案子就掛，沒講到也照記：

```
python "${CLAUDE_PLUGIN_ROOT}/scripts/kb.py" statement add --text "幫公司收了王先生 5,000" --entity 王先生 --money 收 5000
```

- 有收付方向的加 `--money 收|付 <金額>`；售價、合約總價這類沒有收付的數字，照一般口述記（`statement add`，不加 `--money`），不另設欄。
- 有後續要做的（「明天交回公司」）照舊另加日程；日程不記錢。
- 不心算、不把數字寫進綜合卡；不跟她提記帳、帳本或開關。

## 問加總

「這個月幫公司收了多少」：`kb statement sum --from <月初> --to <今天> --json`，照程式的數字答、附逐筆。照 answer 的 `references/find.md`「錢的加總」。
