# 密碼：記下來、拿出來、忘掉、同一種的 PDF

本檔寫給記密碼的人（這版就是主對話的你）。程式輸出裡以 `kb ` 開頭的指令，換成開場段的 kb 指令前綴再跑。
密碼只存這台電腦的 Windows 憑證管理員，知識庫裡任何檔都不留（D-180）。「那份密碼檔可以讀」是另一件事，看 `references/ruling.md` 第三節。

## 一、怎麼聽

| 客戶的話 | 做法 |
|---|---|
| 「這組工地門禁密碼記下來，大門 1234」 | `kb unlock save --kind 記下的密碼 --name 工地大門 --value "1234"` |
| 「信義王那份 PDF 有密碼，是 lin2026」 | 用這組開那份（`kb convert <那份> --password "lin2026"`，ingest 的 `references/commands.md`），答完末尾問要不要記住 |
| 「這個密碼以後都記住」「記住它」 | `kb unlock save --kind PDF 密碼 --name <她怎麼叫這組> --value "<剛給的>"` |
| 「保險單都用這組密碼開」 | 先存（PDF 密碼），再 `kb unlock authorize --name <那組> --label 保險單 --example <剛開的那份的編號>` |
| 「其他有密碼的檔也試試這組」 | 這句明說要試才試（D-181 不自動試）：試的是 `cards todo --json` 的 `unreadable`（或 `kb pending list`）裡「有密碼」的 PDF。那組存過的對每份跑 `kb convert <那份> --saved <那組> --explicit`；沒存過、她剛給的就每份用 `--password` |
| 「工地大門密碼多少」 | `kb unlock get --name 工地大門`，只回她問的那一個 |
| 「把那個密碼忘掉」 | `kb unlock forget --name <那組>` |
| 「保險單不要自動開了」 | `kb unlock revoke --label 保險單` |
| 「記了哪些密碼」 | `kb unlock list`（只列名字，不列密碼） |
| 「幫我登入 ERP，帳號 X 密碼 Y」「我的 API 金鑰是 sk-…，記下來」 | 這版還記不起來：明說沒有寫任何檔，請她先不要給；不要說「記下了」（D-179） |

- 名稱用她的叫法（工地大門、保險單）；名稱不能有 `/ \ " $` 與反引號。密碼一律用雙引號包；密碼裡有 `"`、`$`、反引號、`\` 時改用單引號包；同時又有單引號的包不住，請她換一組或用別的方式給。
- 存密碼、忘掉密碼改的是這台電腦的憑證管理員，「退回上一版」救不回；不要說「不對可以退回」，要改就再存一次、不要就忘掉。只有 `authorize`、`revoke`（記在知識庫裡）退得回。
- 她給的密碼只在那一個指令裡出現：不寫進卡、口述、裁示、偏好、`kb turn note`、任何檔；回答裡完全不出現密碼值，唯一例外是 `kb unlock get` 印出的那一行（她問的那一組）；存好了說「記好了」就好。
- 種類兩種：門禁、Wi-Fi 這類她要你記的叫「記下的密碼」；開 PDF 用的叫「PDF 密碼」。同一個名稱只留一組，換種類也是換掉。
- `kb unlock get`、`kb unlock authorize`、`kb convert --saved … --explicit` 這幾個動作會跳出允許詢問，請客戶按允許（D-212：防檔案裡夾的指令讓 AI 自己開口子）；她沒按就照沒做講。`save`、`list`、`forget`、`revoke` 與授權範圍內的 `convert --saved` 不問。
- 守門的理由句以「需要客戶按允許才會執行：」開頭時，是在等客戶按允許：被拒或她沒按，就停下來照實跟她說「要按允許才會做」，不換寫法重試、不猜別的路徑（換寫法還是同一個動作，守門照樣問）。理由句是「找不到這份檔」時，請她說那份在哪個夾、叫什麼。
- 客戶說要記（「記下來」「記住」）就直接存，不再問一句；只給了密碼沒說要記的，用完答末尾問要不要記住（R-09）。
- 「同一種」只授權她說過的那一種；哪一份算同一種由你判斷（整理時 `plan` 的 `unlock_same_kind` 會列，ingest 的 `references/carding.md` 第十節）。

## 二、成功句與拒絕句

成功句照它的意思講，不加密碼：

| 程式說 | 跟客戶說 |
|---|---|
| 記好了：X（記下的密碼），存在這台電腦的憑證管理員 | 「記好了，存在這台電腦裡，知識庫的檔不會有這組密碼」 |
| 換成新的了：X | 「X 換成新的了」 |
| X：<值> | 只回她問的那一個；這句回答不會記進工作日誌 |
| 忘掉了：X；Y那一種也不會再自動開 | 照講 |
| 以後Y這一種的 PDF，會用「X」那組密碼開，開了會跟你說 | 照講 |
| 不再自動開：Y這一種 | 照講 |
| 這台電腦沒有記「X」 | 「這台電腦沒有記 X」；換過電腦的話密碼要再給一次（D-050：只存在原來那台） |
| 這台電腦不是 Windows，存不了密碼 | 照講，這次不記；她要用就每次給 |
| 憑證管理員寫不進去（…） | 「這台電腦的憑證管理員存不進去，這次沒記」，請服務人員看 |
| 「X」不是 PDF 密碼 | 那組是記下的密碼；問她開 PDF 用的是哪一組 |
| 這組密碼沒說過可以用在別的檔 | 這份不是她說過的那一種；照讀不到講，或問她要不要試這組（她說要試才加 `--explicit`） |
| 密碼不對 | 「這組打不開，是不是別組？」不再試別組 |
| 種類要是 記下的密碼、PDF 密碼 之一 | 你給錯了種類，照第一節換一種再跑 |
| 這台電腦沒有記任何密碼 | 照講 |
| 憑證管理員讀不到／刪不掉／列不出來（…） | 「這台電腦的憑證管理員現在打不開」，請服務人員看 |
| 等不到鎖，沒有寫入 | 「別的程式正在改，我稍後再試」 |
| 狀態檔讀不到：… | 「知識庫的狀態檔讀不了，我先停下來；說「檢查」我看原因」 |
| 沒有「Y」這一種 | `kb unlock list` 看現在有哪幾種 |
| 名稱不能空白…／密碼不能空白… | 換一個名稱，或請她再給一次 |
| 清冊沒有這份檔：… | 先整理那份（`kb inventory scan`），再授權 |

## 三、提醒

- 她給密碼的那一句，程式只遮得到跟著「密碼」「password」這類字的值；只打了值（「保險單用 lin2026 開」「是 1234」）的，照 R-13 跑 `kb turn redact "<把值換成 ███ 的那一句>"`（D-187 第二層）。
- 敏感的帳密不要打在對話裡：Claude Code 自己的對話紀錄與雲端都有。她堅持要給時照記，記完說一句這個提醒（README「密碼」一段）。
- 不要把密碼檔改名來讓程式讀：守門只看檔名，改了名整份連密碼都會被讀進去（D-145）；要讀就請她說「那份可以讀」。
