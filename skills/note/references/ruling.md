# 裁示：只有這件這樣

本檔寫給記個案裁示的人（這版就是主對話的你）。程式輸出裡以 `kb ` 開頭的指令，換成開場段的 kb 指令前綴再跑。

## 一、三種裁示（可以讀在第三節）

| 客戶的話 | 種類 | 指令 |
|---|---|---|
| 「信義王的報價以口述為準」「這份合約照我說的算」 | 口述為準 | `kb ruling add --kind 口述為準 --entity <名稱> --text "<客戶原話>"`（只蓋某幾份檔就改 `--card <卡的編號>`） |
| 「合約.docx 是舊的，別信」「那份估價單作廢了」 | 不採用 | `kb ruling add --kind 不採用 --card <卡的編號> --text "<客戶原話>"` |

- **口述為準**：綜合卡現況把客戶說的版本當現在的說法放前面，原檔的寫法標「原檔寫 X」留著。要有對應的口述（客戶說了什麼），沒記過就先照 `references/correction.md` 記一條口述再記裁示。
- **不採用**：綜合卡現況不再引用那幾張卡，紀事已寫的照留，卡與原檔都不刪。檔名找卡：先看 `總目錄.md`，找不到就問是哪一份；有兩份同名的就問是哪一份。
- 掛的實體：客戶說的名稱實體清單沒有，先問「<名稱> 是新的案子／對象嗎？」，客戶說是才 `kb entity add`；說是別的名字就照那個名字。
- 記了以後相關的實體列進待更新綜合卡，下次整理時照裁示改。
- 那份原檔之後改了版，程式會在回答末尾問「現在可以信了嗎」，照 `kb asks --json` 給的結果做（可以了 → 收回；還是別信 → 記下新版、不再問）。
- 客戶說「那份合約現在可以信了」「信義王不用再以口述為準」：`kb ruling list --json` 找到那條，`kb ruling remove <編號>`。

## 二、規則還是個案

- 「以後報價都以口述為準」：改規則沒有這種設定，不寫偏好；回「這版只能一件一件記，你說哪一件以你說的為準，我就記那一件」（裁示只蓋那一件，D-041）。
- 「信義王的報價以口述為準」只講這個案子：裁示。
- 分不清是這件還是以後都這樣，就問一句「是只有這件，還是以後都這樣？」。
- 「這兩份報價不算重複，一份給業主、一份內部用」不是裁示：記成一條口述（D-149）。

## 三、可以讀：檔名像密碼的那一份

檔名像密碼或金鑰的檔預設不讀；客戶說「那份網站密碼檔可以讀」就記一條可以讀的裁示，守門與 `kb convert` 只放讀那一份（D-183）。

| 客戶的話 | 指令 |
|---|---|
| 「網站密碼.xlsx 可以讀」 | `kb ruling add --kind 可以讀 --file <那份的清冊編號或路徑> --text "<客戶原話>"` |
| 「網站帳號密碼那種檔都可以讀」（指著一份說） | 同上，多帶 `--label <她怎麼叫這一種>`（例：網站密碼表）；之後同一種的新檔程式會問一句 |
| 「那份密碼檔不要讀了」 | `kb ruling list --json` 找到那條，`kb ruling remove <編號>`；卡上本來就沒有密碼，不用清 |
| 「那份不要讀」（還沒說過可以讀的） | `kb ruling decline --file <那份>`，之後不再問 |

- `kb ruling add --kind 可以讀` 這幾個動作會跳出允許詢問，請客戶按允許（D-212，跟 `kb unlock get`、`authorize`、`convert --saved … --explicit` 一樣）；她沒按就照沒做講。`kb ruling decline` 不問。
- 找那份：還沒做卡，總目錄沒有它；用 `ls` 或 Glob 列那個夾的檔名（只列檔名守門放行，D-185），把路徑給 `--file`；找不到就請她說在哪個夾、叫什麼。
- 可以讀跟著那份檔走：搬到別的登記夾、改名、內容改了都照樣讀得到；搬進她說不讀的夾就不讀（不讀最優先，D-184）。
- 記了以後照 ingest 整理那份（卡上只寫這份是什麼、列了哪些項目的名字，任何值都不抄，ingest 的 `references/carding.md` 第十節）。
- 她問裡面的某一組（「建材商訂貨網的密碼是什麼」）：answer 照 `kb lookup` 找到那張卡，`kb convert` 讀原檔，只回她問的那一行（answer 的 `references/find.md`）。
- 「同一種」：有帶 label 的可以讀之後，新的檔名像密碼的檔進來，`kb asks` 會多 `credential_same_kind` 一題，附那些 label 與例子。你判斷是同一種才問「又有一份「X」，跟之前的網站密碼表一樣可以讀嗎？」（題目裡的種類名照你判斷的那一種換），照結果做；判斷不是任何一種就跑「不是同一種（不問）」那個結果，不問她（D-181）。
- 提醒不要把檔名改掉來讓程式讀：守門只看檔名，改了名整份連密碼都會被讀進去（D-145）；要讀就說「那份可以讀」。
- 「這組門禁密碼記下來」不是裁示：看 `references/password.md`。

## 四、成功句與拒絕句

成功句照它複述。拒絕句轉白話、不繞過去：

| 程式說 | 跟客戶說 |
|---|---|
| 已記下裁示（不採用）：「…」—… | 好，之後整理不再引用「…」 |
| 已記下裁示（口述為準）：… | 好，…以你說的為準，原檔的寫法也會留著 |
| 已收回裁示：… | 好，…照原檔整理（收回的是可以讀：「好，那份又不讀了」） |
| 已對過新版，還是不採用：「…」 | 好，新版也不採用，不會再問 |
| 已記下裁示（可以讀）：「…」 | 好，「…」可以讀了，我只讀這一份 |
| 記下了：「…」不讀，之後不再問 | 好，那份不讀 |
| 裁示種類要是 口述為準、不採用、可以讀 之一 | 換成這三種之一；都不是就照第二節判斷是不是規則；「這組密碼記下來」看 `references/password.md` |
| 可以讀要指定是哪一份檔（--file） | 找到那份再記；找不到就問在哪個夾、叫什麼 |
| 這份本來就讀得到 | 「這份檔名不像密碼，本來就讀得到」，不用記 |
| 清冊沒有這份檔：… | 先 `kb inventory scan`，還是沒有就問在哪個夾 |
| 可以讀只掛檔（拿掉 --entity、--card）／只有可以讀才用 --file | 照它拿掉再記 |
| 裁示裡不要放密碼；要記的話跟我說『記下來』…／種類名稱裡不要放密碼… | 原話或種類名稱裡別帶密碼本身，換個說法再記；她要記那組密碼看 `references/password.md` |
| 不採用要指定是哪幾張卡（--card） | 找到那份檔的卡再記；找不到就問是哪一份 |
| 不採用只掛卡，不掛實體（拿掉 --entity） | 拿掉實體、只掛卡再記 |
| 口述為準要掛實體或卡 | 問是哪個案子或哪份檔 |
| 實體清單沒有「X」，先 kb entity add | 問「X 是新的案子／對象嗎？」，說是才登記，說是別的名字就照那個名字 |
| 清冊沒有…／這份還沒有檔案卡 | 這份還沒整理成卡，先整理再記 |
| 沒有這條裁示／這條裁示已經收回了 | 重跑 `kb ruling list --json` 找現在有效的那條 |
| 等不到鎖，沒有寫入 | 「別的程式正在改，我稍後再試」，不重複硬跑 |
